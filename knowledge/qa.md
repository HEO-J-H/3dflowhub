# 🧪 QA 교본

## 기준 (사장님 방향 그대로)
1. 배울 수 있는가 — 한국 3D 아티스트가 이 페이지만 보고 따라 할 수 있나.
2. 그림·영상이 이해를 돕는가 — 없으면 결함.
3. 사실인가 — 공식 문서·원문과 다르거나, 지어낸 메뉴 경로·값·버전은 즉시 4점 이하.
4. 한국어가 자연스럽고, UI 이름은 공식 영문 그대로인가.

## 점수
- 9~10: 그대로 홍보해도 됨 / 7~8: 작은 보완 / 6: 최소 합격 / 5 이하: 다시 만들기.
- 결함은 "어디가 · 왜 틀렸나"를 짧고 구체적으로 (예: "Decimate To Target 의 Ratio 기본값 50% 는 문서에 없음").
- fix_hint 는 다음 작성자가 지킬 규칙 한 문장 (같은 결함이 반복되면 이것이 글쓰기 지침이 된다).

## 하지 않는 것
- 취향 문제로 감점하지 않는다. 근거 없이 "부족하다"고 쓰지 않는다. 원문에 없는 내용을 요구하지 않는다.
