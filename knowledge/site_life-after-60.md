# 💰 life-after-60 사이트 교본 (이 사이트 소속 직원이 읽음)

## 사이트
- 은퇴 현금흐름 시뮬레이터: 60세 은퇴 목표로 자산·국민연금·퇴직/개인연금·ISA·세금·건강보험을 넣어 **월별 현금흐름**을 계산.
- 계산은 사용자 브라우저에서만(개인정보 서버 저장 없음). 엑셀 내보내기·차트·시나리오 비교.
- 독자: 50~60대 은퇴 준비자, 그 가족. 숫자에 민감하고, 신뢰가 가장 중요.

## 절대 원칙 (이 사이트 특수)
1. **법률·세무·투자 자문 금지.** "도구 안내용, 일반 요지" 를 유지. "~하세요(투자 권유)" 대신 "~를 시뮬레이션해 볼 수 있습니다".
2. **법규·계산식·시뮬 로직은 자동 변경 금지.** 직원은 '검토 제안' 만 — 근거(공식 발표·기사 링크)와 함께. 반영은 사람이 공식 출처
   (law.go.kr·국세청·국민연금공단·보건복지부·금융위·금융투자협회) 대조 후 regulatory-reference.js 수정 + REVIEW_STAMP 갱신.
3. **확정 vs 논의 구분.** 기사에 '추진·검토·논의·발의'면 아직 확정 아님 → "모니터링" 으로 분류, 사이트 수정 제안 금지.
   '국회 통과·공포·**국무회의 의결(시행령·개정안)**·고시·시행일 확정' 이면 "반영 검토" 제안을 반드시 올린다
   (사이트 기준에 해당 항목이 없더라도 — 예: 군 복무 크레딧 확대 → 국민연금 가입기간 계산 안내에 영향 여부 검토).
   논의 단계 이슈는 note 에 "모니터링: 항목 — 상태" 로 짧게 남긴다.
4. 숫자는 출처에 있는 그대로. 반올림·추정 금지.

## 규정 감시 체크리스트
- 비교 대상: current_site_rules_summary(사이트 현재 기준) vs recent_news_headlines.
- 우선 감시: 국민연금(보험료율·소득대체율·수령 나이·크레딧), 기초연금(기준연금액·선정기준액), 연금소득세율·분리과세 한도,
  연금저축/IRP 세액공제 한도·공제율, ISA(납입·비과세 한도·만기 이전), 퇴직소득세, 건강보험(보험료율·피부양자), 금융소득 종합과세.
- 제안 형식: 제목 "[확정/논의] 항목 — 바뀌는 점", 근거 = 기사 제목+날짜, source = 링크, 제안 = 사이트의 어느 문구를 확인할지.
- 같은 이슈는 한 번만. 이미 사이트 기준에 반영된 내용(예: 2025 국민연금 개혁)은 제안하지 않는다.

## 홍보 (마케터)
- 채널: 네이버 블로그·카페(재테크·은퇴 준비), 카카오톡 오픈채팅, 페이스북 — 50~60대가 많은 곳.
- 메시지: "내 연금·세금 넣으면 월별로 얼마 쓰는지 보여주는 무료 도구", "개인정보 저장 없음", 실제 고민 장면
  (퇴직금 일시금 vs 연금, 국민연금 연기수령, ISA 만기 활용) — 결론을 주지 말고 '직접 비교해 보기' 로 유도.
- 금지: 수익 보장·"무조건"·특정 금융상품 추천·공포 마케팅.

## 디자인 (디자이너)
- 다크 네이비 + 골드 톤 유지. 50~60대 가독성: 본문 17px 이상, 대비 4.5:1 이상, 버튼 44px, 숫자는 큰 글씨.
- 홍보 이미지 테마는 navy-gold (사이트 색), 핵심 숫자 하나를 크게.
