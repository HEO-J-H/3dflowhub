# ✍️ 에디터 교본 (소식 요약 · 도구별 정리 · 편집 전략)

## 소식 요약
- 제목(25~45자): **도구/제품 이름을 맨 앞에**, 그다음 핵심(무엇이 새롭나). 예: "Blender 4.5 출시 — Vulkan 백엔드와 지오메트리 노드 개선"
  → 단, 기능명은 영문: "Blender 4.5 출시 — Vulkan 백엔드·Geometry Nodes 개선"
- 요약 1문장: 누가·무엇을·왜 중요한가.
- 인사이트(3~5문장): 한국 실무자 관점의 **해석** — 누가 써야 하나, 작업 흐름에 어떻게 넣나, 주의점. 원문 재진술 금지.
- 섹션 4~6개: 사실 위주, 원문에 있는 것만.

## 주제 판별 (relevance)
- 3D 소프트웨어/엔진/VFX/AI 3D 와 **직접** 관련 있어야 함.
- 이름만 같은 다른 것 = 0점: 마술사 해리 후디니, 마야 문명·사람 이름 Maya, 주방용 블렌더, 'unity' 일반 단어,
  주가·투자만 다루는 기사, 일반 PC 하드웨어 벤치마크(3D 작업 언급 없으면), 게임 출시 소식(제작 기술 언급 없으면).

## 분류
- category = **도구/제품**(3ds Max, Blender, Unreal Engine…). 콘텐츠 유형(업데이트·튜토리얼)은 topic 에.
- 도구가 여러 개면 기사의 주인공 하나. 없으면 해당 분야의 '기타 …'.

## 도구별 정리 (월간 roundup)
- 제목: "[도구] 최근 한 달 핵심 정리" 류, 40자 이내.
- 소개 3~4문장: 이번 달 흐름(무엇이 많이 나왔나, 큰 변화 1개).
- 핵심 포인트 3~5개: 각 1문장, 구체적(버전·기능명).
- 먼저 볼 글: 실무에 바로 쓸 수 있는 순서로, 이유 한 줄.

## 편집 지침을 만들 때 (전략 성찰)
- 지침은 측정 가능한 행동으로: "제목에 도구명 앞에 두기", "튜토리얼은 단계 수를 제목에" 등.
- 6개 이하. 효과 없던 지침은 교체.
