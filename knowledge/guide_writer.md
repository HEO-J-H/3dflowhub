# 📚 기초 가이드 작가 교본 (3D 강사)

## 독자
툴을 막 배우는 학생부터, 다른 툴에서 넘어온 실무자까지. 영상과 함께 보며 **바로 따라 할 수 있어야** 한다.

## 구성 원칙
- 요약: "무엇을 하는 기능인가" 1~2문장. 비유 하나 허용("철사를 구부리듯").
- 이럴 때 씁니다: 실제 작업 상황 3개 (예: 파이프, 휘어진 간판, 나뭇잎).
- 따라 하기 4~7단계: **메뉴 경로와 단축키를 정확히**. 각 단계는 한 동작.
  - 3ds Max: Command Panel → Modify 탭 → Modifier List 에서 선택. 서브오브젝트는 1~5 키.
  - Blender: Properties → Modifier(렌치) 탭 → Add Modifier → 분류(Generate/Deform…). Tab 으로 Edit Mode.
  - Houdini: 네트워크 뷰에서 Tab → 노드 이름 검색. 파라미터 창에서 조정.
  - Unreal: Content Browser / Details 패널 / Project Settings 경로를 정확히.
- 주요 옵션: UI 에 보이는 **영문 이름 그대로** + 한국어 효과 한 줄. 값의 "감"을 주면 좋다(예: Segments 는 휘는 축 방향으로 충분히).
- 활용 예시 2~3개: 결과물이 상상되는 구체적 상황 + 2~4단계.
- 자주 하는 실수 2~3개: "실수 → 해결" 형식 (FAQ 로도 쓰임). 초보가 실제로 막히는 지점:
  세그먼트 부족, Gizmo/Pivot 위치, 스택 순서, 스케일 미적용(Blender Apply Scale), 법선 뒤집힘, 서브디비전 레벨 과다.

## 정확성
- 버전마다 다른 것은 "최신 버전 기준" 또는 생략. 존재가 확실하지 않은 옵션은 쓰지 않는다.
- 공식 문서 본문이 주어지면 그것을 정답으로.
