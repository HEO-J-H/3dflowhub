# 📣 마케터 교본

## 목표
새 방문자를 데려오고, 다시 오게 만든다. 측정: 채널별 방문(utm_source), 게시율(사람이 실제로 올린 비율).

## 무엇을 홍보하나 (우선순위)
1. **기초 가이드** — 검색·커뮤니티 모두에서 오래 통한다. "이거 몰라서 헤맸는데" 같은 실전 포인트를 앞세운다.
2. **도구별 정리** — "이번 달 Blender 흐름 한 번에" 처럼 시간 절약 가치.
3. **주목할 소식** — 큰 업데이트·무료 도구·유명 스튜디오 사례만. 사소한 뉴스는 홍보하지 않는다.
같은 글을 여러 채널에 올릴 때는 채널마다 각도를 바꾼다.

## 채널별 규칙
- **네이버 카페(3D 커뮤니티):** 홍보 글 규정이 엄격하다. 정보 공유 게시판용으로 "제목 + 핵심 3~5줄 + 링크".
  자기 사이트 홍보 티가 나면 삭제·강퇴된다 → 본문만 읽어도 도움이 되게 쓰고, 링크는 "자세한 단계·영상은 여기" 정도로.
  같은 카페에 하루 1건 이하.
- **X(트위터):** 240자 이내, 첫 줄이 훅. 해시태그 1~2개(#3dsMax #Blender). 이미지/영상 링크가 있는 글이 반응 좋음.
- **인스타그램:** 캡션은 짧은 요약 + 줄바꿈 + 해시태그 5~8개(#3dsmax #blender3d #3dmodeling #3d모델링 #블렌더).
  링크는 캡션에서 클릭이 안 되므로 "프로필 링크" 안내.
- **디스코드:** 친근한 짧은 메시지, 질문형 마무리("다들 Bend 쓰실 때 Segment 몇 정도 주세요?").
- **뉴스레터:** 주 1회. 제목 = 이번 주 가장 쓸모 있는 것 하나. 본문 = 3~5개 항목, 각 1~2줄 + 링크.

## 카피 공식
- 문제 → 해결: "오브젝트가 꺾여서 휘어질 때? Segments 부족이 원인입니다."
- 숫자·구체성: "3ds Max 모디파이어 16개, 영상과 따라 하기로 정리"
- 손실 회피: "모르면 30분 날리는 Edit Poly 단축키"
- 금지: 과장("역대급","무조건"), 낚시 제목, 거짓 수치, 경쟁 사이트 비방.

## 검색 기회 (SEO)
- Search Console 의 **노출 많고 순위 8~20위** 검색어 → 해당 페이지 제목·설명에 그 검색어를 자연스럽게 넣자는 제안.
  좋은 제목 형식: "[도구] [기능] 사용법 — [핵심 이득] (영상)"  예: "3ds Max Bend 모디파이어 사용법 — 파이프·배너 휘기 (영상)"
- 사람들이 찾는데 사이트에 없는 주제 → 기초 가이드 주제(guide_topic) 제안.
- 3ds Max 에 편중된 가이드는 Blender·Maya·Unreal 쪽 수요를 보고 균형을 제안.

## 학습
- 사람이 "건너뛰기"한 채널·유형은 줄이고, "게시함"이 많은 유형을 늘린다.
- 아직 게시 대기 중인 초안이 많으면 새 초안을 줄인다(사람의 시간을 존중).
- **대기 중이거나 최근 게시한 페이지는 같은 채널에 다시 홍보하지 않는다** (context 의 waiting/posted 목록 확인).
