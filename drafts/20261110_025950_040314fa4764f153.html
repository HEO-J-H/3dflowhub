한 줄 요약 — RefineSplat은 3D Gaussian Splatting과 2D 추적을 결합하여 오픈 텍스처 3D 객체 검색 및 분할 정확도를 높이는 연구입니다.

RefineSplat의 객체 중심 패러다임

기존 기법들은 전체 장면을 먼저 복원한 뒤 라벨을 붙이는 방식을 주로 사용합니다. 이 연구는 먼저 2D에서 객체를 추적한 후 각 객체를 별도의 3D Gaussian 그룹으로 재구성합니다. 이를 통해 명확한 객체와 Gaussian 간의 대응 관계를 보존합니다.

2D 추적과 3D 재구성의 피드백 루프

기존 비디오 트래커가 생성하는 오류 마스크를 보완하기 위해 렌더링된 마스크와 다각도 일관성을 활용합니다. 이 피드백 메커니즘을 통해 객체 추적 결과를 정밀하게 교정합니다.

Viewport 인식 임베딩 할당 전략

각 객체에 단일 언어 임베딩을 부여하는 대신 여러 뷰로 클러스터링된 임베딩을 유지합니다. 이를 통해 시점에 따라 달라지는 세부적인 시각적 의미 정보를 안정적으로 담아냅니다.

Blender-OVS 합성 벤치마크 도입

정적 및 동적 시퀀스로 구성된 Blender-OVS 벤치마크를 새롭게 제안합니다. 실제 객체 메시와 포인트 클라우드를 포함하여 추출된 지오메트리를 정밀하게 직접 평가할 수 있습니다.

💡 에디터 코멘트

기존의 분할 후 병합 방식 대신 2D 추적과 3D 재구성을 양방향으로 피드백하여 객체 경계의 모호함을 줄이고 뷰 일관성을 유지합니다.

❓ 자주 묻는 질문

Q. RefineSplat은 어떤 문제를 해결하나요?
A. 기존 3D Gaussian Splatting 기반 오픈 텍스처 검색에서 발생하던 뷰 불일치, 모호한 객체 경계, 약한 객체 수준 대응 문제를 해결합니다.
