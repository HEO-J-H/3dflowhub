NVIDIA RTX Blackwell의 NVFP4와 어텐션 병목 현상

NVIDIA RTX Blackwell 아키텍처는 하드웨어 가속 4비트 행렬 곱셈을 지원하는 NVFP4를 도입하여 BF16보다 높은 Tensor Core 처리량을 제공합니다. 비디오 생성 모델에서 BF16 추론 시 어텐션은 주로 MMA 연산에 의해 병목이 발생하며, 이를 해결하기 위한 정교한 데이터 이동과 스케줄링 조율이 필요합니다.

레지스터 리사이클링을 통한 SageAttention3 커널 최적화

최적화된 SageAttention3 커널은 각 N128 스코어 타일을 두 개의 N64 레지스터 슬롯으로 분할합니다. 소프트맥스 양자화 후 레지스터를 재사용함으로써 현재 타일의 남은 연산과 다음 타일의 QK 연산을 중첩시킵니다.

FlashInfer 통합 및 월드 모델 추론 성능 향상

이 핵심 최적화 코드는 FlashInfer 메인 브랜치에 병합되어 광범위한 채택이 가능해졌습니다. Reactor는 실제 프로덕션 서빙 스택에 이 커널을 통합하여 LongLive, Helios, OmniDreams, Cosmos 3 Nano 워크로드에서 엔드투엔드 추론 지연 시간을 최대 15.34% 단축했습니다.

💡 에디터 코멘트

NVIDIA RTX PRO 6000 Blackwell에서 NVFP4 4비트 행렬 곱셈을 활용해 어텐션 연산 지연 시간을 최대 1.64배 단축하고 FlashInfer 메인 브랜치에 병합되었습니다.
