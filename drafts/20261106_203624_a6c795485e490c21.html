DCC 내부에서 확인하는 리뷰 노트

슈퍼바이저의 수정 지시 사항이 웹 브라우저가 아닌 DCC 내부의 Zeno 인터페이스로 직접 전달됩니다. 노트를 클릭하는 즉시 해당 프레임으로 이동하며 샷 카메라를 통해 드로잉 위치를 그대로 파악합니다.

프레임 누락을 막는 작업 흐름

기존 리뷰 방식은 웹 플레이어와 Blender 같은 DCC 화면을 번갈아 보며 프레임을 수동으로 찾아야 했습니다. 이 과정에서 발생하는 프레임 오인식이나 수정 누락 문제를 줄이기 위해 씬 데이터 자체에 노트를 연결했습니다.

씬 파일에 영향을 주지 않는 구조

노트 데이터와 드로잉 표시는 작업 중인 원래의 씬 파일에 영구적으로 추가되지 않습니다. 외부에서 뷰어 형태로 오버레이되어 아티스트의 로컬 작업 파일을 깔끔하게 유지합니다.
