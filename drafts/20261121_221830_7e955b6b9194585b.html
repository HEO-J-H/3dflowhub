한 줄 요약 — Godot 4에서 Steam용 게임을 처음 배포할 때 필요한 8가지 설정 항목을 정리한 체크리스트입니다.

분류: Game Engine › Godot › 튜토리얼·팁

1. Steamworks SDK 준비

Steamworks SDK는 Steam 파트너 사이트에서 무료로 다운로드할 수 있습니다. 압축을 풀어 프로젝트 루트에 ‘steamworks_sdk’ 폴더를 만든 뒤, Godot 4 Export Preset에서 경로를 지정합니다. SDK 버전은 Godot 4와 호환되는 최신 버전을 사용해야 합니다.

2. Export Preset에 Steam 옵션 추가

Export → Presets 메뉴에서 ‘Add…’를 클릭하고 ‘Steam’ Template을 선택합니다. ‘Steam App ID’, ‘Steam Build Directory’, ‘Steamworks SDK Path’를 각각 입력합니다. 이 설정이 없으면 Steam 빌드 시 실행 파일이 정상적으로 패키징되지 않습니다.

3. 인증서와 앱 ID 입력

Steam 파트너 대시보드에서 발급받은 앱 ID와 배포용 인증서를 Export Preset에 입력합니다. 인증서는 ‘steam_appid.txt’ 파일에 저장하고, 빌드 폴더에 복사해 두어야 합니다. 잘못된 ID나 누락된 인증서는 Steam Client에서 실행 오류를 일으킵니다.

4. 파일 시스템 권한 설정

Steam은 특정 파일 구조를 요구합니다. ‘steamapps/common/YourGame’ 폴더에 실행 파일과 데이터 파일을 배치하고, ‘userdata’ 폴더는 쓰기 권한을 부여합니다. Godot 4 Export 옵션에서 ‘Include PCK in EXE’를 켜면 파일 관리가 간편해집니다.

5. 테스트 빌드 실행

설정이 완료되면 ‘Export Project’ 버튼을 눌러 Windows용 빌드를 생성합니다. 생성된 exe 파일을 Steamworks SDK에 포함된 ‘steamclient.dll’과 함께 실행해 정상 동작을 확인합니다. 로그에 ‘SteamAPI_Init() succeeded’가 표시되면 성공적인 초기화입니다.

6. 배포 전 최종 검증

Steamworks SDK의 ‘SteamPipe’ 툴을 사용해 빌드 파일을 업로드하고, Steam 테스트 서버에서 실행해봅니다. 오류가 없으면 파트너 대시보드에서 ‘Ready to Release’ 상태로 전환합니다. 이 단계에서 발견되는 작은 설정 오류가 배포 지연의 주요 원인입니다.

💡 에디터 코멘트

8개의 체크포인트를 모두 점검하면 작은 팀도 Steam 빌드 실패를 크게 줄일 수 있습니다. Steamworks SDK를 프로젝트 루트에 정확히 배치하고, Export Preset에 앱 ID와 인증서를 입력하는 단계가 핵심입니다.
