C++와 Direct3D 12로 구축한 RetroEngine

RetroEngine은 1인 개발자 Alex Rybak이 C++와 Direct3D 12를 기반으로 완전히 새로 작성한 커스텀 게임 엔진입니다. 범용 엔진에 단순한 후처리기 필터를 얹은 형태가 아니라 디스플레이 모델 자체를 목표로 설계되었습니다.

하드웨어와 아날로그 디스플레이에서 얻은 영감

개발자는 어린 시절 사용하던 세가 제네시스, 닌텐도 Entertainment 시스템과 1998년산 CRT 텔레비전 환경에서 영감을 받았습니다. 군 복무 시절 위성 엔지니어로 근무한 경력과 Full Sail에서의 게임 아트 및 디자인 학위가 기술적 기반이 되었습니다.

스택 전체를 직접 소유하는 개발 방식

렌더러, 애니메이션 시스템, Audio 믹서, 세이브 시스템, Script 시퀀스, 월드 에디터까지 모든 Runtime 요소가 개발자의 독자적인 코드로 이루어져 있습니다. UI 편집에만 MIT 라이선스의 Dear ImGui를 예외적으로 사용하여 외부 엔진 업데이트에 종속되지 않는 독립성을 확보했습니다.

💡 에디터 코멘트

C++와 Direct3D 12 기반으로 렌더러부터 Audio 믹서, 세이브 시스템까지 모든 Runtime 코드를 직접 작성해 레트로 디스플레이 질감을 구현했습니다.

❓ 자주 묻는 질문

Q. RetroEngine은 어떤 기술 스택으로 개발되었나요?
A. C++ 언어와 Direct3D 12 API를 기반으로 처음부터 직접 작성되었습니다.

Q. 엔진 내부에서 서드파티 코드는 전혀 사용되지 않았나요?
A. 에디터 UI 구성에만 몇 달의 개발 시간을 절약하기 위해 MIT 라이선스의 Dear ImGui를 사용했으며, 게임 Runtime 코드는 모두 독자 코드입니다.
