한 줄 요약 — 오토데스크가 Maya와 3ds Max에 에이전틱 AI 도구인 Autodesk Assistant와 외부 AI 연결을 위한 MCP 서버를 기술 프리뷰로 도입했습니다.

분류: 3D DCC › Maya › 업데이트·출시

Autodesk Assistant의 제어 권한과 안전 장치

Autodesk Assistant는 씬 체크와 UV 맵핑 같은 작업을 대신 수행할 수 있습니다. 읽기-쓰기 모드는 기본적으로 꺼져 있으며, 사용자가 'Allow'를 클릭해야만 Script가 실행됩니다. 또한 안전 모드가 기본 활성화되어 파일 시스템을 직접 변경하거나 시스템 명령어를 실행하는 작업을 차단합니다.

외부 AI 에이전트를 연결하는 MCP 서버

새롭게 추가된 3ds Max 및 Maya MCP 서버를 통해 외부 클라이언트 AI 에이전트가 두 프로그램을 직접 제어할 수 있습니다. 이를 활용해 개발자는 툴 테스트 과정을 자동화할 수 있으며, 토큰 기반 인증과 동일한 승인 단계를 거쳐 작동합니다.

NVIDIA DLSS 기반 Arnold 대화형 Viewport

Arnold의 새로운 대화형 Viewport는 NVIDIA DLSS를 활용해 디노이징과 Upscaling을 처리합니다. 작업자가 씬을 이동할 때는 낮은 지연으로 부드럽게 상호작용하고, 멈추면 세부 묘사가 정밀하게 정착됩니다.

Flow Capture 및 Flow Production Tracking AI 연동

Autodesk Assistant는 Flow Capture와 Flow Production Tracking에도 도입되었습니다. 사용법 질의에 답할 뿐만 아니라, 허가된 그룹의 경우 애니메이터의 작업 진행 상황 같은 프로덕션 데이터 요약 정보를 제공합니다.

💡 에디터 코멘트

Autodesk Assistant는 읽기-쓰기 모드에서 Script 실행 전 사용자의 'Allow' 승인을 요구하며, 안전 모드를 통해 파일 시스템 접근을 차단해 작업 파일 무결성을 지킵니다.

❓ 자주 묻는 질문

Q. Autodesk Assistant의 Script 실행 권한은 어떻게 제어하나요?
A. 읽기-쓰기 모드는 기본적으로 꺼져 있으며, Script가 실행되기 전에 반드시 사용자가 'Allow' 버튼을 눌러야 합니다. 또한 안전 모드가 외부 파일 조작이나 시스템 명령어 실행을 막습니다.

Q. Arnold Viewport의 DLSS 기능은 어떤 역할을 하나요?
A. NVIDIA DLSS 기술이 Upscaling과 디노이징을 담당하여, 씬을 편집하는 동안 라이팅과 그림자를 부드럽고 빠르게 실시간으로 미리 볼 수 있게 해줍니다.
