한 줄 요약 — Nevercenter가 가벼운 3D 모델링 Software Silo 2027.0을 출시하며 새로운 Script 편집기와 외부 AI 도구 연동을 위한 MCP 서버를 추가했습니다.

분류: 3D DCC › 기타 DCC › 업데이트·출시

Silo 2027.0 주요 업데이트 개요

Nevercenter는 가벼운 속도로 잘 알려진 3D 모델링 Software Silo의 최신 버전 2027.0을 공개했습니다. 이번 버전은 프로그램 전반의 안정성을 다지는 동시에 외부 개발 및 AI 연동성에 초점을 맞춘 기능들을 포함하고 있습니다.

새로운 Script 편집기 탑재

작업 편의성을 높이기 위해 새롭게 설계된 Script 편집기가 도입되었습니다. 사용자 지정 Script를 작성하고 디버깅하는 과정이 한층 매끄러워졌으며, 반복 작업을 자동화하는 데 유용하게 활용할 수 있습니다.

MCP 서버를 통한 외부 AI 도구 연동

가장 눈에 띄는 변화는 MCP 서버 추가로, 이를 통해 외부 AI 도구와 Silo를 연결할 수 있습니다. AI 기반 워크플로를 모델링 파이프라인에 결합하려는 작업자들에게 실질적인 연결 고리를 제공합니다.

💡 에디터 코멘트

이번 업데이트에 포함된 MCP 서버 도입은 외부 AI 도구와 Silo를 직접 연결하여 모델링 작업 환경을 확장할 수 있게 만듭니다.

❓ 자주 묻는 질문

Q. Silo 2027.0에서 가장 큰 변화는 무엇인가요?
A. 새로운 Script 편집기와 외부 AI 도구 연동을 지원하는 MCP 서버가 추가된 점이 핵심입니다.

Q. MCP 서버는 어떤 용도로 사용되나요?
A. Silo와 외부 AI 도구를 서로 연결하여 데이터 교환 및 AI 기반 작업 연동을 돕는 역할을 합니다.
