한 줄 요약 — Corona 렌더러를 설치하지 않고도 3ds Max 내에서 Corona 머티리얼을 Physical Material로 변환하는 Python 기반 오픈소스 Script가 공개되었습니다.

분류: 3D DCC › 3ds Max › 플러그인·스크립트

개발 배경

Blender로 .max 파일을 여는 프로젝트에서 V-Ray와 Corona 머티리얼 지원을 확인한 개발자가 3ds Max에서도 동일한 접근이 가능하도록 구상했습니다. Corona 플러그인 설치 여부와 상관없이 머티리얼 구조를 다루기 위해 독립적인 Script로 제작되었습니다.

기술 요구 사항 및 검증 버전

작동을 위해 Python 3 이상 버전이 필요하며, 3ds Max 2026 버전에서 다양한 Corona 머티리얼 포함 장면을 대상으로 테스트를 거쳤습니다. 외부 렌더러 종속성을 없애 에셋 호환성을 높이는 데 초점을 맞추었습니다.

관련 소스코드와 설치 및 실행 방법은 GitHub 페이지(3d-rille/3ds Max---corona-materials-importer)에서 확인할 수 있습니다. 오픈소스 형태로 공개되어 있어 누구나 코드를 확인하고 직접 환경에 맞춰 실행해 볼 수 있습니다.
