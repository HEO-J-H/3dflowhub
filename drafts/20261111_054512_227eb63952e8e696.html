한 줄 요약 — SoftPAT3D는 텍스트 Prompt만으로 변형 가능한 물체를 물리적으로 유효한 형태로 자동 생성해 씬을 완전한 접촉 상태로 만든다.

분류: AI 3D › 기타 AI 3D › 연구·논문

핵심 아이디어: 물리‑보강 텍스트‑투‑3D

논문은 텍스트‑투‑3D 생성에 물리 시뮬레이션을 결합해 변형 가능한 물체를 실제 물리적 제약을 만족하도록 만든다. 기존 방법은 변형 물체를 생성하면 메쉬가 자체 교차하거나 물성 정보가 없어 시뮬레이션에 사용할 수 없었다.

변형 객체 파이프라인

SoftPAT3D는 생성된 메쉬에서 제조 과정 기반의 ‘rest shape’를 추출하고, 사전 정의된 재료 라이브러리로 초기 탄성 파라미터를 할당한다. 이후 물체를 Prompt가 지정한 지지면 위에 최적화 가능한 위치에 놓고, 단일 접촉 모델로 정적 평형을 계산한다.

배치 최적화와 Grid 서치

Prompt와 일치하지 않을 경우, SoftPAT3D는 물체 배치를 Grid 서치로 조정한다. 차별 가능한 시뮬레이션의 adjoint를 이용해 Grid가 놓치기 쉬운 미세 위치와 재료 파라미터를 동시에 최적화한다.

성능 평가

총 65개의 텍스트 Prompt에 대해 SoftPAT3D는 모든 씬에서 교차(interpenetration)를 완전히 제거했다. 비교 대상 시스템은 최소 하나 이상의 교차를 보였으며, SoftPAT3D의 씬은 바로 로봇 매니퓰레이션과 편집 작업에 활용 가능했다.

💡 에디터 코멘트

SoftPAT3D는 65개 Prompt 모두에서 객체 간 침투를 0%로 달성했으며, 이는 로봇 매니퓰레이션이나 물리 기반 애니메이션 파이프라인에 바로 사용할 수 있는 씬을 즉시 제공한다는 의미다.
