한 줄 요약 — VersionGS는 고속 모션 구간에서 발생하는 동적 Gaussian Splatting의 화질 저하를 해결하기 위해 프레임별 상태를 직접 인코딩하고 공유 딕셔너리를 활용하는 최적화 기법을 제어합니다.

분류: AI 3D › 가우시안 스플래팅 › 연구·논문

고속 모션에서의 화질 저하 문제

기존 동적 Gaussian Splatting 기법들은 시간의 부드러운 함수나 프레임 간 제한된 업데이트 방식으로 시간 변화를 인코딩합니다. 이로 인해 빠른 움직임이 포함된 댄스 시퀀스 등에서는 저속 모션 구간에 비해 PSNR이 1.1에서 4.0 dB까지 급격히 떨어지는 한계가 있습니다.

VersionGS의 프레임별 상태 인코딩

VersionGS는 프레임별 Gaussian 상태를 직접 인코딩하고 모션 추정은 오직 재구성 가이드 용도로만 사용합니다. 각 프레임 그룹 내에서 변하지 않은 Gaussian은 공유 딕셔너리의 기존 버전을 유지하고, 수정된 Gaussian은 새로운 버전으로 추가합니다.

선택적 순차 구축과 버전 재사용 극대화

광학 흐름, 사진 차이, 렌더링 오차를 기반으로 선택된 Gaussian만 정제하고 나머지는 그대로 두어 버전 재사용을 극대화합니다. 이후 딕셔너리를 프루닝하고 시뮬레이션된 양자화로 파인튜닝한 뒤 이미지 형태로 인코딩합니다.

저장 공간과 재생 성능의 균형

프루닝 비율을 조정하는 방식만으로 딕셔너리를 다시 구축하지 않고도 저장 공간과 화질 사이의 균형을 조절할 수 있습니다. 재생 과정은 별도의 모션 모델이나 Neural Network 없이 순수하게 3DGS 래스터라이저만 사용하여 빠르게 동작합니다.

💡 에디터 코멘트

DanceNet3D 벤치마크 기준 기존 최고 모델 대비 전경 PSNR을 2.7 dB 향상시키며, 최고 속도 모션 구간에서도 화질 저하를 0.3 dB 미만으로 제한합니다. 대규모 저장 공간이 필요한 씬에서 TAD-GS 대비 5.7배에서 6.0배 적은 저장 공간만으로 더 높은 PSNR을 달성합니다.
