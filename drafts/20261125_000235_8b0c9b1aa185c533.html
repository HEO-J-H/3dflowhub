한 줄 요약 — Unity CLI가 Asset Store 및 60개 이상의 AI 생성 모델과 연동되어 코딩 에이전트가 필요한 에셋을 직접 검색, 다운로드, 생성할 수 있게 됩니다.

분류: Game Engine › Unity › 업데이트·출시

코딩 에이전트를 통한 Asset Store 직접 접근

Unity CLI는 Claude Code, Codex, Grok Build, Google Antigravity 등의 코딩 에이전트와 Unity Asset Store를 연결합니다. 이제 에이전트가 프로젝트에 필요한 에셋을 직접 찾고 다운로드하여 씬에 배치할 수 있습니다. 브라우저를 열거나 수동으로 임포트하는 과정 없이 작업이 이루어집니다.

Asset Library 플러그인으로 단일 프리팹 추출

새롭게 출시된 Asset Library 플러그인은 Unity CLI와 결합하여 기존 .unitypackage 형식을 분해합니다. 전체 팩을 받을 필요 없이 필요한 단일 모델이나 프리팹만 개별 다운로드할 수 있습니다. 삼각형 폴리곤 수와 애니메이션 리깅 데이터가 함께 제공되어 프로덕션 준비 상태를 미리 확인할 수 있습니다.

60개 이상의 AI 제너레이터 연동

원하는 에셋이 존재하지 않거나 팀에 아티스트가 없는 경우, 코딩 에이전트가 60개 이상의 AI 생성 모델을 활용해 스프라이트, 3D 모델, 사운드 효과 등을 직접 제작합니다. 명령어 하나로 생성뿐만 아니라 배경 제거 및 Upscaling 편집도 가능합니다. 생성된 모든 파일에는 모델, Prompt, 비용 기록이 함께 저장됩니다.

단일 Unity ID 계정 통합과 오픈 베타

기존에 사용하던 Unity ID로 로그인하면 Asset Store와 60개 이상의 생성 모델을 추가 설정 없이 이용할 수 있습니다. 에이전트는 사용자의 권한과 크레딧을 그대로 사용하여 에셋을 검색하고 견적을 요청합니다. 현재 Asset Store in the CLI와 AI Generators in the CLI는 모두 오픈 베타로 제공 중입니다.

💡 에디터 코멘트

650MB 규모의 전체 에셋 팩 대신 단일 프리팹만 선택해 다운로드할 수 있는 Asset Library 플러그인이 도입되어 프로젝트 용량 관리가 간소화됩니다.

❓ 자주 묻는 질문

Q. Unity CLI를 통해 어떤 코딩 에이전트들을 연결할 수 있나요?
A. Claude Code, Codex, Grok Build, Google Antigravity 등의 코딩 에이전트를 Unity Asset Store 및 AI 제너레이터와 연결하여 사용할 수 있습니다.

Q. 전체 에셋 팩을 다운로드하지 않고 단일 에셋만 받을 수 있나요?
A. 네, 새롭게 출시된 Asset Library 플러그인이 Unity CLI와 연동되어 대용량 Package 대신 필요한 단일 프리팹이나 모델만 골라서 다운로드하고 임포트할 수 있습니다.

Q. AI 제너레이터 사용 시 별도의 계정을 만들어야 하나요?
A. 아니오, 기존에 보유한 Unity ID로 로그인하면 연결된 계정 플랜과 AI 크레딧을 통해 60개 이상의 생성 모델을 추가 설정 없이 바로 이용할 수 있습니다.
