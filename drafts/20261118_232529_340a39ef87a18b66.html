Adobe AI 에이전트의 네이티브 프로젝트 파일 직접 수정 계획

Adobe는 2027년 초에 AI 에이전트가 사용자의 네이티브 프로젝트 파일을 직접 수정하고 편집할 수 있는 기능을 선보일 예정입니다. Quasa.io의 보도에 따르면 이 기술은 크리에이티브 Software 전반의 작업 방식을 바꿀 잠재력을 지니고 있습니다. 사용자는 AI에게 직접 명령을 내려 레이어나 Timeline 설정을 수정하도록 지시할 수 있게 됩니다.

2027년 초 출시 일정과 예상되는 변화

구체적인 세부 기능은 아직 공개되지 않았으나, 2027년 초 배포를 목표로 개발이 진행되고 있습니다. 기존의 단순한 텍스트 기반 Prompt 생성 방식을 넘어, 실제 프로젝트 파일 내부 구조를 이해하고 제어하는 단계로 진화합니다. 후반 작업 스튜디오에서 단순 반복 편집 업무의 비중이 줄어들 것으로 예상됩니다.
