한 줄 요약 — Maxon이 Cinema 4D의 스캐터 기능과 ZBrush의 UV 에디터를 강화한 2027.0 버전을 공개했습니다.

분류: 3D DCC › Cinema 4D › 업데이트·출시

Maxon 2027.0 Release 개요

Maxon은 최신 소프트웨어 버전인 2027.0을 통해 자사 주요 3D 솔루션의 핵심 기능을 대거 업데이트했습니다. 이번 버전은 특히 Cinema 4D와 ZBrush의 사용자 작업 환경 최적화에 초점을 맞추었습니다. 전반적인 툴셋의 유기적인 연동과 성능 안정을 도모한 것이 특징입니다.

Cinema 4D 스캐터 기능 강화

Cinema 4D 2027.0에서는 에셋 배치와 복제를 담당하는 스캐터 기능이 대폭 개선되었습니다. 복잡한 자연물이나 대규모 객체를 장면 내에 효율적으로 분산 배치할 수 있습니다. 이를 통해 복잡한 환경 디자인 작업에서 아티스트의 작업 속도가 빨라집니다.

ZBrush UV 에디터 개편

ZBrush 2027.0은 정밀한 텍스처 작업의 핵심인 UV 에디터 기능을 새롭게 개편했습니다. 고도화된 모델링 데이터의 UV 언랩과 편집 과정이 한층 직관적으로 변했습니다. 외부 DCC 툴과의 연동 없이도 스컬프팅 환경 내에서 효율적인 UV 작업을 지원합니다.

실무 파이프라인 적용 효과

이번 업데이트는 시각효과와 모션 그래픽 프로덕션의 제작 효율을 높이는 데 기여합니다. 대규모 씬 구성과 세밀한 캐릭터 텍스처링 단계를 하나의 생태계 안에서 매끄럽게 처리할 수 있습니다. 작업자들은 반복 작업을 줄이고 창의적인 영역에 더 집중할 수 있는 환경을 갖추게 되었습니다.

💡 에디터 코멘트

이번 2027.0 Release는 대규모 환경 구축과 캐릭터 텍스처링 작업을 자주 수행하는 아티스트들의 작업 병목을 직접적으로 해결합니다. 특히 ZBrush 내 UV 편집 기능의 개선은 외부 프로그램으로 데이터를 오가는 왕복 횟수를 줄여 전체 파이프라인의 효율성을 크게 높여줍니다. 모션 그래픽과 캐릭터 아티스트 모두 실무 제작 공정에서 즉시 도입하여 체감 성능을 시험해 볼 가치가 있습니다. 복잡한 지형 구성과 고도화된 텍스처 작업을 병행하는 스튜디오 파이프라인에 유용한 업그레이드입니다.
