Linux 환경 기본 Vulkan 적용

Blender 5.3은 Linux 운영체제에서 Vulkan 백엔드를 기본 설정으로 제공합니다. 기존 OpenGL 중심의 구동 방식에서 벗어나 최신 그래픽 API 기반으로 작동합니다.

Viewport 성능과 안정성 강화

Vulkan 백엔드를 기본으로 사용함에 따라 Linux 시스템에서의 Viewport 렌더링 성능과 전반적인 작업 안정성이 개선되었습니다.

💡 에디터 코멘트

A. Linux 환경에서 Vulkan이 기본 그래픽 백엔드로 설정되었습니다.

A. Vulkan 백엔드가 기본 활성화되어 최신 하드웨어 환경에서 더 안정적인 Viewport 작업을 수행할 수 있습니다.
