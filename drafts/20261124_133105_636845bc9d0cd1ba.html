분류: Game Engine › Unity › 튜토리얼·팁

Preset Manager 기능 소개

Unity Preset Manager는 프로젝트 에셋의 임포터, 컴포넌트, Scriptable GameObject 설정을 정의하고 자동화하는 도구입니다. 에셋을 프로젝트에 가져올 때 일관된 규칙을 적용하여 반복 작업을 줄여 줍니다.

픽셀 아트 에셋 설정 자동화

픽셀 아트 텍스처는 일반 텍스처와 다른 압축 및 필터링 설정이 필요합니다. Preset Manager를 활용하면 특정 조건이나 폴더 경로에 맞춰 Point filter 모드와 무압축 옵션을 자동으로 적용할 수 있습니다.

일반 에셋과의 설정 분리

도구를 사용해 픽셀 아트와 일반 텍스처의 서로 다른 Import 설정을 충돌 없이 유지할 수 있습니다. 프로젝트 내 에셋 종류에 따라 별도의 규칙을 정의하여 수동 설정 실수를 방지합니다.

💡 에디터 코멘트

Pixel Art 텍스처에 Point 필터 모드와 무압축 설정을 일일이 수동으로 적용하는 번거로움을 줄여 줍니다.

❓ 자주 묻는 질문

Q. Unity Preset Manager는 어떤 역할을 하나요?
A. 프로젝트 에셋의 Import 설정, 컴포넌트 값, Scriptable GameObject 설정을 미리 정의하고 자동 적용하는 기능을 제공합니다.

Q. 픽셀 아트 텍스처에는 어떤 설정을 적용하나요?
A. Point filter 모드와 무압축 설정을 적용하여 픽셀의 선명함을 유지하고 도트 그래픽 특유의 품질을 살립니다.
