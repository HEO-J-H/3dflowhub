UV 좌표와 3D 표면의 관계

UV는 3D 모델의 표면에 2D 이미지의 어느 부분이 표시될지 지정하는 좌표계입니다. 캐릭터 얼굴에 눈, 코, 입을 정확히 그려 넣으려면 이 좌표 체계를 이해해야 합니다.

Seam을 이용한 절개선 생성

Seam은 입체적인 3D 모델을 2D 평면으로 펼치기 위해 모델 표면에 긋는 절개선입니다. 캐릭터의 구조에 맞춰 눈에 띄지 않는 곳에 Seam을 배치하는 것이 중요합니다.

UV Unwrap과 Mapping의 실행

UV Unwrap은 Seam을 기준으로 3D 모델 표면을 2D로 펼치는 작업입니다. UV Mapping은 펼쳐진 2D 전개도 위에 이미지를 대응시켜 3D 모델에 질감과 색상을 입히는 과정입니다.

💡 에디터 코멘트

초보자가 가장 어려워하는 3D 표면을 2D로 펼치는 원리를 Seam 절개선과 매핑 과정을 통해 직관적으로 이해할 수 있습니다.

❓ 자주 묻는 질문

Q. Blender에서 Seam은 무엇인가요?
A. Seam은 3D 모델을 2D 평면으로 펼치기 위해 자르는 절개선 역할을 합니다.

Q. UV Unwrap과 UV Mapping의 차이는 무엇인가요?
A. Unwrap은 3D 표면을 2D로 펼치는 작업이며, Mapping은 2D 이미지를 펼쳐진 표면에 대응시키는 과정입니다.
