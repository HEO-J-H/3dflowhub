NVIDIA cuPotential의 모듈형 C API 구성

NVIDIA cuPotential은 분자 동역학 시뮬레이션에서 계산 병목인 장거리 상호작용 평가를 최적화하는 모듈형 C API Primitive를 제공합니다. 개발자는 스택의 여러 레이어에서 특정 컴포넌트를 선택하여 워크로드를 가속할 수 있습니다. 컷오프 기반 상호작용 평가기와 전하 확산 함수 같은 직접 공간 및 역공간 유틸리티를 포함합니다.

OpenMM 플러그인 통합 및 속도 향상

이 라이브러리는 OpenMM에 쉽게 통합할 수 있는 전용 플러그인을 제공하여 비결합력, 랑방 적분기, 몬테카를로 바로스탯을 최소한의 코드 수정으로 대체합니다. T4부터 RTX PRO 6000 Blackwell까지의 GPU 아키텍처 벤치마크 결과, 24,000~400,000개 원자 시스템에서 NPT 조건 기준 2배에서 3배 이상의 엔드투엔드 속도 향상을 기록했습니다.

C2 연속 분할 및 확산 함수를 통한 정확도 개선

D. E. Shaw Research 및 Flatiron Institute와 공동 개발한 새로운 C2 연속 분할 및 확산 함수는 표준 Ewald 및 u-시리즈 방법에 비해 낮은 Grid Resolution와 축소된 컷오프에서도 목표 정확도를 달성합니다. 10ns 동안의 에너지 드리프트 측정 결과 cuPotential은 기본 PME 설정 대비 드리프트를 수백 배 줄여 생체 분자 시뮬레이션 요구 사항을 충족합니다.
