한 줄 요약 — World Labs가 6개의 Atlas 엔드포인트를 API 키 기반으로 공개하며, 그중 하나로 Gaussian Splatting 데이터를 3D 메시로 변환하는 기능을 제공합니다.

분류: AI 3D › 가우시안 스플래팅 › 업데이트·출시

Atlas API 엔드포인트 공개

World Labs는 총 6개의 Atlas 엔드포인트를 API 키 방식으로 접근할 수 있도록 공개했습니다. 개발자와 아티스트는 해당 API를 통해 공간 컴퓨팅 및 3D 모델링 관련 다양한 AI 연산을 외부 프로그램에서 직접 호출할 수 있습니다.

Gaussian Splatting을 메시로 변환하는 기능

제공되는 6개의 엔드포인트 중 핵심 기능 하나는 Gaussian Splatting 결과물을 폴리곤 구조의 3D 메시로 변환하는 것입니다. 기존에는 Splatting 데이터를 게임 엔진이나 3D DCC에서 쓰기 위해 거쳐야 했던 복잡한 변환 과정을 자동화합니다.

실무 적용과 접근성

이번 API 공개로 인해 3D 스캔 데이터를 활용하는 작업실에서는 클라우드 기반 자동 변환 파이프라인을 구축할 수 있게 되었습니다. API 키를 통한 접근 방식을 지원하므로 자체 소프트웨어나 커스텀 툴에 쉽게 연동 가능합니다.

💡 에디터 코멘트

Gaussian Splatting 데이터를 전통적인 3D 메시로 곧바로 변환할 수 있는 API 엔드포인트가 제공되어 후반 작업의 수작업 Retopology 단계를 줄일 수 있습니다. 게임 엔진이나 3D DCC 환경으로 바로 가져가 편집해야 하는 에셋 제작 흐름에 유용합니다.
