에이전트 실행 경로 확인

AI 에이전트가 Unreal MCP를 감지했음에도 프로젝트 내에서 작업을 수행하지 못한다면, 가장 먼저 에이전트를 어디서 실행했는지 점검해야 합니다. 올바르지 않은 디렉토리나 경로에서 에이전트를 구동하면 프로젝트와 통신할 수 없습니다.

서버 구동 상태 점검

MCP 서버가 로컬 환경에서 정상적으로 실행 중인지 확인하는 과정이 필요합니다. 서버가 꺼져 있거나 연결이 끊어진 상태라면 에이전트는 프로젝트 내의 도구에 접근할 수 없습니다.

Toolsets 활성화 여부

프로젝트 설정이나 에디터 환경에서 필요한 toolsets가 켜져 있는지 확인해야 합니다. 기능이 비활성화되어 있으면 에이전트가 사용할 수 있는 도구 목록이 비어 있는 상태로 나타납니다.

대형 작업 요청 분할

복잡하고 무거운 도구 호출을 한 번에 요청하면 에디터가 일시적으로 멈춘 것처럼 보일 수 있습니다. 작업을 작은 단위의 요청으로 나누어 처리하면 반복 작업 속도를 유지하고 에디터 응답 중단을 방지할 수 있습니다.

💡 에디터 코멘트

AI 에이전트가 긴 툴 호출을 처리하는 동안 에디터가 멈춘 것처럼 보일 때는 큰 작업을 작은 요청 단위로 나누어 전송하면 작업 흐름이 끊기지 않습니다.

❓ 자주 묻는 질문

Q. AI 에이전트가 도구를 전혀 인식하지 못할 때 무엇부터 확인해야 하나요?
A. 에이전트가 실행된 경로, MCP 서버의 실행 여부, 그리고 툴셋(toolsets) 활성화 상태를 차례대로 점검해야 합니다.

Q. 오랜 시간이 걸리는 도구 호출 시 에디터가 멈추는 현상은 어떻게 해결하나요?
A. 거대한 작업 요청을 더 작은 여러 개의 요청으로 쪼개서 에이전트에 전달하면 에디터 멈춤 현상을 줄일 수 있습니다.
