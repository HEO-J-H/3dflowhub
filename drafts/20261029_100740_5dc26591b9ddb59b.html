한 줄 요약 — Polyweft는 동일한 공통 조상 메시를 기반으로 독립적으로 수정된 두 개의 Blender 파일을 비교하고, 충돌하는 데이터를 선택하여 하나의 메시로 병합해 주는 오픈소스 도구입니다.

분류: 3D DCC › Blender › 플러그인·스크립트

Polyweft의 기본 개념과 작동 방식

Polyweft는 공통 조상 메시와 두 개의 네이티브 Blender 파일을 검토하여 준비된 하나의 메시 내에서 독립적인 편집 내용을 유지합니다. 두 브랜치에서 동일한 값을 변경한 경우 명시적인 선택을 요구하여 충돌을 해결합니다. 제공되는 Tide 예제는 256개의 버텍스와 224개의 쿼드 리본 메시로 시작하며, 좌측 전용 편집 18개, 우측 전용 편집 19개, 그리고 세 개의 충돌 값을 포함합니다. 충돌하는 버텍스는 좌표를 섞는 대신 하나의 완전한 XYZ 벡터로 선택됩니다.

병합 범위 및 기술적 제한 사항

이 도구의 범위는 의도적으로 버텍스 위치, UV 페이스 코너, 그리고 동일한 토폴로지와 준비된 식별자를 가진 상태에서의 Principled Base Color/Roughness 기본값으로 엄격히 제한됩니다. 토폴로지 변경, 임의의 준비되지 않은 씬, 리깅, 전체 씬은 조율하지 않으며 수치 병합 후에도 Blender에서의 예술적 검검이 필요합니다. 모든 그 외의 데이터는 우측 파일의 내용을 따릅니다. 클라우드 서비스나 계정, AI API 없이 로컬에서 실행됩니다.

요구 사항 및 네이티브 병합 프로세스

네이티브 병합을 위해서는 Python 3.11 이상과 로컬 Blender 실행 파일이 필수적입니다. 공식 Blender 4.5.14 LTS 버전(Linux)과 로컬 Blender 5.3 알파 빌드에서 테스트되었으며, Windows와 공식 안정화 macOS 조합은 아직 검증되지 않았습니다. 사용자는 웹 기반 리뷰를 먼저 체험하거나 Blender 4.5 Tide 파일과 Python wheel을 다운로드하여 로컬에서 검토하고 충돌을 선택한 뒤 Blender를 통해 적용할 수 있습니다.

출력 결과 및 오픈소스 라이선스

Polyweft는 새로운 .blend 파일을 저장하고 별도의 Blender 프로세스로 이를 다시 열어 허용된 페이로드를 확인합니다. 제공된 병합 Tide 파일은 세 가지 충돌에 대해 왼쪽 선택 항목을 기록하며 원본 입력 바이트는 유지됩니다. 본 소프트웨어는 GPL-3.0-or-later 라이선스를 따르는 무료 프로그램입니다. 메시 병합 분야의 기존 선행 연구로는 MeshGit과 BlenDiff가 존재합니다.

💡 에디터 코멘트

다수의 아티스트가 동일한 에셋을 분할 작업한 후 데이터를 통합해야 하는 협업 Pipeline 매우 유용하게 활용할 수 있습니다. 토폴로지 변경이 없는 상태에서 버텍스 위치와 UV, 머티리얼 속성 등의 충돌을 명시적으로 제어할 수 있어 버전 관리 효율을 높여줍니다. 다만 아직 리눅스 및 일부 알파 버전 위주로 검증되었고 토폴로지 변경이나 리깅 데이터는 지원하지 않으므로, 도입 전 프로덕션 환경의 파이프라인 호환성을 신중히 검토해야 합니다.

❓ 자주 묻는 질문

Q. Polyweft를 사용하려면 어떤 환경이 필요한가요?
A. Python 3.11 이상과 로컬 Blender 실행 파일이 필요하며, Linux 환경의 공식 Blender 4.5.14 LTS 및 Blender 5.3 알파 빌드에서 테스트되었습니다.

Q. Polyweft로 병합할 수 있는 데이터의 범위는 어디까지인가요?
A. 토폴로지가 변경되지 않은 상태에서의 버텍스 위치, UV 페이스 코너, 그리고 Principled Base Color와 Roughness 기본값으로 제한됩니다. 리깅이나 토폴로지 변경은 지원하지 않습니다.
