FlexPart 프레임워크 개요

FlexPart는 텍스트 제어를 통해 3D 메시를 의미론적으로 분할할 수 있는 통합 프레임워크입니다. 3D 에셋은 다양한 방식으로 파츠를 분해할 수 있으며, 이 모델은 사용자가 원하는 세분화 수준을 반영합니다. 핵심 원칙은 사용자가 요구하는 그대로의 파츠를 정확히 추출하는 것입니다.

다중 세분화 데이터셋과 제어 Prompt

유연한 제어를 달성하기 위해 위치 및 형상 절이 포함된 의미론적 파츠 이름으로 구성된 전체론적 제어 Prompt를 도입했습니다. 이를 뒷받침하기 위해 자동화된 Vision-Language Model 파이프라인을 활용하여 다중 세분화 파티션과 대응하는 Prompt로 구성된 대규모 데이터셋을 구축했습니다. 이 데이터를 기반으로 모델은 뷰에 독립적인 파츠 아이덴티티 필드를 네이티브 3D 공간에 생성합니다.

랜덤화된 배경 드로핑과 학습 방식

기하학적 사전 지식에만 의존하지 않고 모델이 의미론적 조건을 철저히 따르도록 강제하기 위해 무작위 배경 드로핑 기법을 사용하여 학습을 진행했습니다. 이 방식은 모델이 텍스트 Prompt의 의미적 지시에 더욱 집중하도록 유도합니다. 결과적으로 에셋의 시각적 노이즈나 배경 요소에 흔들리지 않고 정확한 세분화 성능을 유지합니다.

추론 시점 VLM 플래너의 역할

추론 시점에 작동하는 VLM 플래너는 2D 렌더링 결과물로부터 서술적 절을 자동으로 완성해 줍니다. 이를 통해 사용자는 복잡한 입력 없이 일상적인 언어로 원하는 파츠의 이름을 간단히 지정할 수 있습니다. 사용자의 간결한 입력만으로도 선택적 분할 작업에서 뛰어난 성능을 발휘합니다.

성능 평가 및 벤치마크 결과

플래너가 완성한 Prompt를 사용하는 FlexPart는 정답 가이드라인을 받은 가장 강력한 기존 베이스라인보다 mIoU 측면에서 15% 더 우수한 성능을 기록했습니다. 별도의 홀드아웃 벤치마크인 FLEXPARTBENCH에서는 모든 세분화 수준에서 선두를 차지하며 평균 mIoU를 22% 향상시켰습니다. 선택적 분할 작업에서도 기존 베이스라인 대비 IoU를 35% 끌어올렸습니다.

💡 에디터 코멘트

이 연구는 기존 3D 파츠 분할의 한계였던 고정된 단위와 데이터 부족 문제를 VLM 파이프라인으로 해결하여 실무에서 에셋 재조합이나 리깅 전처리를 자동화할 수 있는 가능성을 보여줍니다. 특히 사용자가 원하는 파츠의 이름을 입력하면 뷰에 상관없이 정밀한 파츠 아이덴티티를 3D 공간에 할당하므로, 대규모 3D 에셋 라이브러리 정리 및 자동화 파이프라인 구축에 큰 도움이 됩니다. 향후 게임 에셋 관리나 AI 기반 3D 모델링 워크플로우에 도입될 경우 수동 파츠 분할 작업을 대폭 줄여줄 수 있어 주목할 만합니다.
