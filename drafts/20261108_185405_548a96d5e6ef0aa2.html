분류: Game Engine › Unity › 업데이트·출시

UI Toolkit 프로스트 글래스 깊이 효과

Unity 6.6의 UI Toolkit은 네이티브 프로스트 글래스 깊이 효과를 지원합니다. 이를 통해 UI 요소 간의 시각적 계층 구조를 직관적으로 표현할 수 있습니다.

uGUI SafeArea 노치 대응

uGUI에서는 별도의 복잡한 Script 작성 없이 SafeArea 노치 영역을 손쉽게 처리할 수 있습니다. 모바일 디바이스 화면 상단과 하단의 베젤 영역에 UI가 침범하는 문제를 간편하게 방지합니다.

💡 에디터 코멘트

UI Toolkit에 추가된 네이티브 프로스트 글래스 깊이 효과는 Shader 작성 없이 현대적인 인터페이스를 구현할 때 불필요한 드로우 콜 최적화 작업을 줄여줍니다.

❓ 자주 묻는 질문

Q. Unity 6.6에서 UI Toolkit은 어떤 새로운 시각 효과를 제공하나요?
A. 네이티브 프로스트 글래스 깊이 효과를 제공하여 반투명한 레이어와 깊이감 있는 인터페이스를 쉽게 구성할 수 있습니다.

Q. uGUI의 SafeArea 노치 핸들링은 어떻게 작동하나요?
A. 모바일 화면의 노치와 절단면을 자동으로 인식하여 UI 배치가 화면 안전 영역 내에 유지되도록 돕습니다.
