한 줄 요약 — Unity CLI를 활용해 터미널 환경에서 여러 씬의 라이트맵, 라이트 프로브, 반사 프로브 Baking을 자동화하는 방법입니다.

분류: Game Engine › Unity › 튜토리얼·팁

Unity CLI를 활용한 반복 작업 제거

여러 씬의 조명을 굽기 위해 매번 씬을 열고 대기하던 방식을 터미널 명령으로 바꿉니다. 터미널에서 단일 명령어로 다중 씬의 조명 Baking을 일괄 처리할 수 있습니다.

C#을 이용한 커스텀 CLI 명령 작성

C# 코드를 작성해 Unity CLI에 자체 명령어를 추가하는 방법을 다룹니다. 몇 줄의 코드만으로 실행 중인 에디터와 통신하고 내장 명령을 확장할 수 있습니다.

라이트맵과 프로브 일괄 Baking

라이트맵, 라이트 프로브, 반사 프로브, 환경 라이팅을 포함한 Baking 과정을 자동화합니다. 일정한 카메라 뷰를 캡처하여 검수 과정을 간소화합니다.

HTML 컨택트 시트 생성

각 씬의 Baking 결과물과 카메라 캡처 뷰를 모아 HTML 형식의 컨택트 시트로 출력합니다. 웹 브라우저를 통해 여러 씬의 조명 상태를 한눈에 비교할 수 있습니다.

💡 에디터 코멘트

터미널 명령 한 줄로 다중 씬 Baking과 HTML 컨택트 시트 생성을 묶어 반복 작업을 줄여줍니다.

A. 라이트맵, 라이트 프로브, 반사 프로브, 환경 라이팅 Baking을 터미널 명령으로 자동화할 수 있습니다.

A. 몇 줄의 C# 코드를 작성하여 Unity 에디터에 연결하고 터미널에서 호출할 수 있는 자신만의 명령을 정의할 수 있습니다.
