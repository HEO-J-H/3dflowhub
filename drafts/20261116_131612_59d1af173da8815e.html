한 줄 요약 — Leartes Studios가 Unreal Engine 5 프로젝트의 에셋 정리와 의존성 시각화를 지원하는 Project Optimization Toolkit 플러그인을 공개했습니다.

분류: Game Engine › Unreal Engine › 플러그인·스크립트

Project Optimization Toolkit 구성과 기능

Leartes Studios가 개발한 Project Optimization Toolkit은 Unreal Engine 5 에디터 내부에서 작동하는 확장 프로그램입니다. Health Dashboard, Asset Cleaner, Dependency Visualizer 세 가지 진단 유틸리티를 하나의 플러그인으로 통합했습니다. 외부 서비스나 서드파티 계정 없이 로컬 환경에서 실행됩니다.

Health Dashboard의 실시간 프로젝트 진단

Health Dashboard는 9개의 특화된 공급자를 통해 프로젝트를 검사하고 0에서 100 사이의 건강 점수와 A부터 F까지의 등급을 부여합니다. 다양한 에셋 정렬 오류에 대한 수정 기능을 제공하며 자동화된 수정 사항은 Ctrl+Z로 되돌릴 수 있습니다.

Asset Cleaner와 Dependency Visualizer 활용

Asset Cleaner는 사용하지 않는 에셋, 중복 파일, 빈 폴더, 손상된 디스크 에셋 등을 자동으로 식별하고 격리합니다. Dependency Visualizer는 참조 구조를 노드와 엣지 그래프로 렌더링하며 실시간 루프 추적을 통해 로드 오더나 쿠킹 실패를 유발하는 순환 참조를 방지합니다.

💡 에디터 코멘트

Unreal Engine 5.1부터 5.8까지 지원하는 이 툴킷은 Health Dashboard로 프로젝트 건강 점수를 0부터 100까지 실시간 측정하고 등급을 매겨 대형 프로젝트의 에셋 관리를 자동화합니다.

❓ 자주 묻는 질문

Q. Project Optimization Toolkit은 어떤 Unreal Engine 버전을 지원하나요?
A. Unreal Engine 버전 5.1부터 5.8까지 지원하며 내장된 Asset Manager Editor 플러그인을 기반으로 작동합니다.

Q. 백그라운드 스캔이 작업에 방해를 주나요?
A. 백그라운드 스캔은 작업자를 차단하지 않으며 무거운 처리나 삭제 작업은 취소 가능한 배치 단위로 수행됩니다.
