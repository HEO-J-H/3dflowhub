Game Developer 팟캐스트의 Mikael Kasurinen 인터뷰

Game Developer.com 공식 팟캐스트 최신 에피소드에서는 Control Resonant의 크리에이티브 디렉터인 Mikael Kasurinen이 출연했습니다. 인터뷰를 통해 도전적인 개발 과정 속에서 내린 주요 결정들을 공유했습니다.

단기간 100만 장 판매를 달성한 개발 전략

Control Resonant는 출시 후 2주 만에 판매량 100만 장을 돌파하며 상업적인 성공을 거두었습니다. 현재 게임 산업 전체가 침체기를 겪는 상황에서 성공 요인을 분석하는 기반 자료를 제공합니다.

게임 개발 교훈을 나누는 팟캐스트 구성

브라이언트 프랜시스가 진행하는 Game Developer 팟캐스트는 격주로 게임 개발 과정의 성공과 실패 사례를 다룹니다. 동료 개발자들이 실무에 적용할 수 있는 전략과 교훈을 공유하는 데 초점을 맞추고 있습니다.
