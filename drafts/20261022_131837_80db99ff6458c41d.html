한 줄 요약 — Wonder Interactive이 AI와 WebAssembly, WebGPU를 활용하여 Unreal Engine 기반 게임을 웹 브라우저 환경에서 실행할 수 있게 해주는 Strata를 공개했습니다.

분류: Game Engine › Unreal Engine › 업계 소식

Strata 기술의 핵심 개요

Wonder Interactive가 개발한 Strata는 고사양 3D 게임 엔진으로 제작된 타이틀을 웹 브라우저에서 구동할 수 있도록 지원하는 솔루션입니다. AI 기술과 최신 웹 표준을 결합하여 무거운 엔진 에셋과 렌더링 파이프라인을 웹 환경에 맞게 최적화합니다. 이를 통해 사용자는 별도의 대형 프로그램 다운로드 없이 링크 클릭만으로 고품질 그래픽을 경험할 수 있습니다.

WebAssembly와 WebGPU의 활용

이 솔루션은 고성능 연산을 지원하는 WebAssembly와 차세대 웹 그래픽 표준인 WebGPU를 적극 활용합니다. 네이티브 앱 수준의 연산 속도와 GPU 가속을 웹 브라우저 내부에서 구현하여 성능 저하를 최소화합니다. 현대적인 웹 브라우저의 하드웨어 가속 기능을 최대한 끌어내어 복잡한 3D 씬을 원활하게 렌더링합니다.

AI 기반 최적화 프로세스

Strata 시스템 내부에 적용된 AI 기술은 웹 환경에 맞게 리소스와 코드를 효율적으로 변환하고 압축하는 역할을 담당합니다. 기존에 웹에서 구동하기 어려웠던 대규모 에셋과 복잡한 Shader를 지능적으로 분석하여 최적화합니다. 개발자는 복잡한 수동 포팅 작업 없이도 기존 파이프라인의 결과물을 웹으로 확장할 수 있는 가능성을 확보하게 됩니다.

웹 게임 및 인터랙티브 콘텐츠의 미래

이 기술은 Unreal Engine 개발자들이 더 넓은 사용자층에게 도달할 수 있는 새로운 유통 채널을 열어줍니다. 설치 장벽이 사라지면서 웹 기반 메타버스, 인터랙티브 쇼룸, 웹 3D 게임의 접근성이 획기적으로 높아집니다. 게임 스튜디오와 콘텐츠 제작사들은 플랫폼 다각화 전략을 세울 때 웹 브라우저를 더욱 강력한 타겟 플랫폼으로 고려할 수 있게 되었습니다.

💡 에디터 코멘트

클라우드 스트리밍 비용을 절감하면서도 고품질 3D 게임을 웹 환경에서 즉시 구동할 수 있다는 점에서 웹 기반 게임 퍼블리싱의 판도를 바꿀 기술입니다. 별도의 무거운 클라이언트 설치 없이 고사양 엔진 빌드를 웹에 올릴 수 있어 마케팅용 플레이어블 빌드나 웹 게임 개발에 큰 변화를 예고합니다. 실무 개발자들은 빌드 최적화와 웹 퍼포먼스 제약을 극복하기 위한 새로운 워크플로를 준비해야 합니다. 특히 WebGPU 지원 브라우저가 확대되는 시점에서 WebGL의 한계를 넘어서는 고성능 웹 3D 서비스를 기획하는 팀에게 유용한 대안이 될 것입니다.

❓ 자주 묻는 질문

Q. Strata는 어떤 엔진과 기술을 지원하나요?
A. Strata는 Unreal Engine 기반의 게임과 콘텐츠를 대상ㄴ으로 하며, AI 기술과 WebAssembly, WebGPU 표준을 활용하여 브라우저 구동을 실현합니다.

Q. 이 기술을 사용하면 어떤 장점이 있나요?
A. 사용자가 별도의 게임 클라이언트를 설치할지 않고도 웹 브라우저에서 고품질 3D 게임과 그래픽을 즉시 즐길 수 있어 접근성이 크게 향상됩니다.
