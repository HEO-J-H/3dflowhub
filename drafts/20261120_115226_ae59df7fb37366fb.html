한 줄 요약 — Ctruh가 103억 개의 폴리곤으로 이루어진 가상 도시 전체를 단일 링크를 통해 웹 브라우저로 실시간 스트리밍하는 Verse Engine을 공개했습니다.

분류: Game Engine › 기타 엔진 › 업데이트·출시

Verse Engine을 통한 대규모 3D 웹 스트리밍 기술

Ctruh는 대형 3D 환경을 웹 브라우저에서 지연 없이 구동하기 위해 Verse Engine을 개발했습니다. 이 엔진은 복잡한 3D 공간 데이터를 클라우드에서 처리한 뒤 사용자에게 스트리밍하는 방식을 사용합니다.

103억 폴리곤 도시 환경의 실시간 구현

이번에 공개된 시연에서는 103억 개의 폴리곤으로 구성된 거대한 도시 모델 전체가 웹 상에서 원활하게 로드되었습니다. 고해상도 지오메트리와 텍스처를 지닌 방대한 데이터셋을 별도의 다운로드 없이 링크 클릭 하나로 접근할 수 있습니다.

설치 없는 브라우저 기반 3D 접근성

사용자는 전용 3D DCC 소프트웨어나 고사양 플러그인을 설치할 필요 없이 표준 웹 브라우저로 접속할 수 있습니다. 링크 공유만으로 클라이언트 기기의 사양 제약을 우회하여 방대한 3D 씬을 탐색합니다.

💡 에디터 코멘트

단일 링크로 103억 폴리곤 규모의 3D 공간을 브라우저에 띄우는 방식은 무거운 데스크톱 뷰어 설치 과정을 생략하고 클라이언트 하드웨어 부담을 낮춥니다. 대규모 건축 시각화나 디지털 튜인 프로젝트를 별도 앱 없이 웹에서 즉시 공유해야 하는 환경에 알맞습니다.

❓ 자주 묻는 질문

Q. Ctruh Verse Engine은 어떤 방식으로 대규모 3D 데이터를 로드하나요?
A. 클라우드 기반 스트리밍 기술을 활용하여 103억 폴리곤에 달하는 도시 전체 데이터를 웹 브라우저로 실시간 전송하여 구동합니다.

Q. 이 기술을 이용하려면 별도의 프로그램을 설치해야 하나요?
A. 별도의 소프트웨어나 플러그인 설치 없이 단일 링크를 통해 웹 브라우저에서 직접 실행할 수 있습니다.
