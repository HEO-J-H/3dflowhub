한 줄 요약 — Unite Tokyo 2026에서 Unity 7 로드맵을 공개하며 Mono에서 CoreCLR로 전환하고 Built‑in Render Pipeline을 URP로 대체한다는 계획을 발표했습니다.

분류: Game Engine › Unity › 업계 소식

CoreCLR 전환 발표

발표자는 Mono에서 CoreCLR로 전환한다는 점을 강조했습니다. CoreCLR는 .NET 5/6 기반으로, 기존 Mono보다 성능과 호환성이 개선됩니다. 도메인 리로드가 제거돼 Script 변경 시 에디터가 즉시 업데이트됩니다.

Built‑in Render Pipeline → URP 전환

Unity 7부터 Built‑in Render Pipeline이 공식적으로 폐지됩니다. 대신 Universal Render Pipeline(URP)으로 마이그레이션을 권장하며, URP는 최신 GPU 기능을 효율적으로 활용합니다. 기존 파이프라인 사용 프로젝트는 단계별 전환 가이드를 제공받게 됩니다.

Unite Tokyo 2026 로드맵 개요

Unite Tokyo 2026 행사에서 Tarrah Alexis, Jason Mann, James Stone이 Unity의 장기 로드맵을 설명했습니다. 핵심 내용은 CoreCLR 도입, URP 전환, 그리고 Unity 7 출시 일정입니다. 발표는 향후 제품 출시와 기능에 대한 기대감을 제시했습니다.

💡 에디터 코멘트

Unity 7에서는 Mono 대신 CoreCLR를 도입해 도메인 리로드가 사라집니다. 이 변화는 Script 수정 후 에디터를 재시작하지 않아도 즉시 반영돼 개발 속도가 크게 향상됩니다.

❓ 자주 묻는 질문

Q. Unity 7에서 Mono는 완전히 사라지나요?
A. 네, Unity 7부터 CoreCLR가 기본 스크립팅 백엔드가 되며 Mono는 더 이상 지원되지 않을 예정입니다.
