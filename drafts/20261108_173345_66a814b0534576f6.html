한 줄 요약 — Unity CLI와 Pipeline 패키지를 활용해 에디터 재시작 없이 실행 중인 게임의 C# 코드와 변수를 실시간으로 제어하는 방법을 설명합니다.

분류: Game Engine › Unity › 튜토리얼·팁

Unity CLI와 터미널 제어 기능

터미널을 통해 Unity 에디터를 설치하고 프로젝트를 관리할 수 있습니다. 도메인 리로드 없이 임의의 C# 코드를 실행하여 작업 속도를 높입니다.

Pipeline 패키지를 이용한 로컬 서버 구축

Pipeline 패키지를 결합하면 Unity를 Edit 모드와 런타임 모두에서 작동하는 로컬 서버로 전환합니다. 게임이 플레이되는 동안 실시간으로 값을 변경할 수 있습니다.

트레일러 제작을 위한 실시간 시각 효과 제어

UI에서 인자를 설정하고 CLI 명령어를 실행하여 게임 내 요소를 테스트하고 수정합니다. 색상 변경, Cinemachine 샷 제어, 속도 및 높이 조정을 실시간으로 처리합니다.

💡 에디터 코멘트

Pipeline 패키지를 사용하면 Edit 모드와 런타임 환경을 로컬 서버로 연결해 트레일러 제작 시 카메라 샷과 게임 속도를 실시간으로 조정할 수 있습니다.

❓ 자주 묻는 질문

Q. Unity CLI는 어떤 역할을 합니까?
A. 에디터 설치, 프로젝트 관리, 도메인 리로드 없는 C# 코드 실행을 터미널에서 직접 수행할 수 있게 합니다.

Q. 실행 중인 게임에서 값을 실시간으로 바꾸려면 무엇이 필요합니까?
A. Pipeline 패키지를 함께 사용하여 Unity를 런타임 서버로 작동시키면 플레이 중에도 값과 설정을 바꿀 수 있습니다.
