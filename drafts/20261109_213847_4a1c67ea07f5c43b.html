Godot 4.8 beta 3 주요 수정 및 개선 사항

이번 베타 3 버전은 Release 후보 단계 전환을 앞두고 잔여 출시 차단 버그 해결에 집중했습니다. 총 51명의 기여자가 74건의 수정 사항을 제출했으며, 주로 이전 베타 버전에서 발생한 회귀 현상 해결에 초점을 맞추었습니다.

3D 및 Shader 노드 추가

3D 기능 측면에서는 LineBase3D가 추가되고 추상 클래스로 지정되었습니다. 또한 Shader 영역에서는 VisualShader 출력 노드에 light vertex 입력이 추가되어 시각적 Shader 작성 범위가 넓어졌습니다.

에디터 안정성 및 입력 버그 수정

에디터 편의성과 관련하여 Save on Focus Loss 기능이 삭제되었던 열린 씬을 다시 생성하던 문제가 수정되었습니다. 메뉴에서 Mouse 모션이 Controller 입력을 덮어쓰던 입력 관련 오류도 함께 해결되었습니다.

.NET 요구 사항 및 테스트 버전 안내

.NET 빌드는 C#을 지원하며 이제 .NET 10.0 이상이 필수입니다. 웹, XR, 안드로이드 전용 에디터도 함께 테스트할 수 있어 다양한 플랫폼 환경에서 검증이 가능합니다.

❓ 자주 묻는 질문

Q. Godot 4.8 beta 3의 .NET 빌드 사용 시 최소 요구 버전은 무엇인가요?
A. .NET 10.0 이상이 필요하며, 기존에 지원되던 .NET 8에서 버전이 변경되었습니다.

Q. 이번 베타 3 버전에서 3D 관련으로 새로 추가된 기능은 무엇인가요?
A. LineBase3D가 새롭게 추가되었으며 추상 클래스로 마크되었습니다.
