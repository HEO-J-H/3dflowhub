Unity 7의 ECS 통합과 기본 성능 향상

Unity 7에서는 모든 GameObject가 엔티티로 동작하며 엔티티-컴포넌트-시스템 변환이 GameObject 변환과 일치합니다. 별도의 복잡한 동기화 과정 없이도 엔진 시스템이 데이터 지향 설계로 이동하면서 프로젝트 성능이 기본적으로 향상됩니다.

직관적인 데이터 편집과 직렬화 시스템 개선

재작업된 직렬화 시스템과 Native Inspector 지원을 통해 실제 Entity 데이터를 GameObject에 직접 추가할 수 있습니다. 커스텀 에디터와 언두 기능, 다중 객체 편집이 기본 설정 그대로 원활하게 작동합니다.

Q. Unity 7에서 GameObject와 ECS의 관계는 무엇인가요?
