한 줄 요약 — 로지텍 G가 Unreal Engine의 Pixel Streaming과 Lumen을 활용해 웹 브라우저에서 실시간으로 구동되는 360° 가상 시뮬레이션 Racing 스튜디오를 공개했습니다.

분류: Game Engine › Unreal Engine › 작품·제작 사례

Logitech G 360° Racing Studio의 기획 배경

로지텍 G는 소비자가 Racing 기어를 개별 부품이 아닌 하나의 완벽한 경험으로 체감할 수 있도록 가상 콕핏 공간을 기획했습니다. 파리 기반의 Unreal Service Partner인 The New Face가 웹사이트 구축을 맡아 실내 공간을 구현했습니다. 가상 환경을 통해 구매자는 장비의 실제 크기, 레이아웃, 인체공학적 배치를 직관적으로 확인할 수 있습니다.

Lumen과 Nanite를 활용한 실시간 렌더링

개발팀은 간접 조명을 실시간으로 처리하는 Lumen과 고밀도 폴리곤 메시를 효율적으로 렌더링하는 Nanite를 도입했습니다. 이를 통해 전통적인 3D 웹 렌더링의 제약을 벗어나 디테일과 조명 표현을 대폭 끌어올렸습니다. 카메라 무브먼트와 시각 효과는 Sequencer를 통해 부드럽게 연동되었습니다.

Pixel Streaming을 통한 웹 접근성 확보

Application을 원격으로 실행하고 렌더링된 프레임을 브라우저로 스트리밍하는 Pixel Streaming 기술이 적용되었습니다. 덕분에 사용자는 고사양 하드웨어나 별도의 프로그램 설치 없이 웹 브라우저에서 고해상도 3D 환경을 경험할 수 있습니다. Salesforce 연동을 통해 쇼룸 관람과 제품 구매가 단절 없이 이어집니다.

💡 에디터 코멘트

Unreal Engine 5의 Pixel Streaming 기능을 활용하면 별도의 고성능 워크스테이션이나 프로그램 설치 없이 웹 브라우저 환경에서도 고품질 실시간 3D 렌더링을 구현할 수 있습니다.

❓ 자주 묻는 질문

Q. Logitech G 360° Racing Studio는 어떤 기술로 제작되었나요?
A. Unreal Engine을 기반으로 제작되었으며, Lumen 동적 글로벌 일루미네이션과 Nanite 가상화 지오메트리를 활용해 고품질 실시간 그래픽을 구현했습니다.

Q. 사용자가 별도의 프로그램을 설치해야 하나요?
A. 아니오. Pixel Streaming 기능을 통해 서버에서 렌더링된 화면을 웹 브라우저로 직접 전송받으므로 별도의 설치 과정이 필요 없습니다.
