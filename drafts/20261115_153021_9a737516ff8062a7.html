분류: 3D DCC › 3ds Max › 튜토리얼·팁

Absolute Transform Mode와 Offset Mode의 기본 동작

3ds Max에서 오브젝트를 이동할 때 사용하는 Transform 모드는 절대 좌표와 상대 이동 거리 중 어느 것을 기준으로 값을 표시할지 결정합니다. 질문자는 Absolute Transform Mode가 좌표를 다시 영점으로 돌려놓은 뒤 다시 Offset Mode로 돌아갔을 때 누적 이동 거리를 보여주는 현상에 의문을 제기했습니다. 두 모드는 입력 창에 값을 넣거나 현재 위치를 읽어들이는 방식에서 차이를 보입니다.

좌표계 표시 방식의 차이점

Offset Mode는 마지막 위치에서 움직인 상대적인 거리를 수치로 보여주는 반면, Absolute Mode는 월드나 피벗의 절대적인 공간 위치를 명시합니다. 오브젝트를 이동한 후 모드를 전환하면 내부적으로 계산된 누적 변환값이 다르게 표시될 수 있습니다. 이로 인해 사용자는 현재 입력된 숫자가 처음 위치 기준인지, 직전 이동 기준인지 혼동을 겪게 됩니다.

💡 에디터 코멘트

Transform Coordinate Center 하단에서 Absolute Mode와 Offset Mode를 전환하면 누적 이동값과 절대 위치 기준 측정 방식을 달리 제어할 수 있습니다.

❓ 자주 묻는 질문

Q. Absolute Transform Mode는 Offset Mode와 무엇이 다른가요?
A. Absolute 모드는 공간상의 절대 위치를 기준으로 값을 표시하고 제어하는 반면, Offset 모드는 직전 위치에서 얼마나 움직였는지 상대적인 이동 거리를 보여줍니다.

Q. Offset Mode로 돌아갔을 때 이전 이동 거리가 그대로 표시되는 이유는 무엇인가요?
A. 모드를 전환하더라도 오브젝트가 거쳐 온 총 변환 데이터가 내부적으로 유지되거나 전환 시점의 기준점이 재계산되기 때문입니다.
