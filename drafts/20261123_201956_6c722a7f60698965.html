한 줄 요약 — Owlchemy Labs가 Unity 멀티 물리 씬과 에너지 스트림 인터랙션을 활용해 XREAL AURA 기기용 XR 아케이드 게임 Hyper Visor를 개발한 기술적 방법을 공개합니다.

분류: Game Engine › Unity › 작품·제작 사례

Hyper Visor와 몰입형 XR 아케이드 설계

Owlchemy Labs는 일상적인 주변 환경을 게임 공간으로 전환하는 XR 아케이드 경험인 Hyper Visor를 개발했습니다. 플레이어는 신비로운 에너지 스트림을 손목 제스처로 발사해 현실 속 균열을 파괴하고 다양한 보스 전과 도전을 수행합니다. 별도의 UI 창을 띄우지 않고 게임플레이 속에서 자연스럽게 대상을 조준하도록 설계되었습니다.

물리 기반 인터랙션과 UI 통합

모든 대상은 Rigidbody를 가진 물리 오브젝트로 구현되어 에너지 빔과 상호작용합니다. 별도의 UI 시스템을 사용하는 대신 타겟 자체가 UI 역할을 겸하도록 설계하여 학습 곡선을 낮추었습니다. 설정 메뉴의 각 버튼도 물리 타겟으로 이루어져 있으며, 에너지 빔을 비추면 원형의 라이프 링이 줄어들며 작동합니다.

멀티 물리 씬을 활용한 월드 및 일시정지 분리

전통적인 일시정지 방식 대신 각 시스템이 고유의 월드와 클럭을 참조할 수 있도록 구조화되었습니다. 모든 시스템은 Instantiate 대신 _world.Spawn()을 호출하며, 월드 조회는 Awake() 시점의 gameObject.scene 매핑을 사용합니다. 각 월드가 독립된 물리 씬에 존재하므로 씬 핸들을 통해 정밀한 제어가 가능합니다.

💡 에디터 코멘트

멀티 물리 씬 구조를 도입하여 플레이어 월드, 게임플레이 월드, 일시정지 월드의 시간과 물리 시뮬레이션을 완벽하게 분리합니다. UI 시스템을 별도로 두지 않고 모든 메뉴 조작을 물리 오브젝트와 Rigidbody 상호작용으로 통합하여 일관된 조작감을 제공합니다.

❓ 자주 묻는 질문

Q. Hyper Visor에서 UI 조작은 어떻게 이루어지나요?
A. 별도의 UI 캔버스를 사용하지 않으며, 게임플레이 타겟과 동일하게 물리 속성이 부여된 3D 오브젝트에 에너지 빔을 비추어 조작합니다.

Q. 일시정지 기능은 어떤 아키텍처로 구현되었나요?
A. 시간과 물리 시뮬레이션을 분리하기 위해 각 오브젝트가 고유의 씬과 연동된 물리 씬 속에서 동작하도록 멀티 물리 씬 구조를 적용했습니다.
