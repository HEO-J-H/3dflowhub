한 줄 요약 — 텍스트나 단일 이미지에서 조명 조절이 가능한 Gaussian Splatting 3D 에셋을 생성하는 VideoRNG 방법론을 제안합니다.

VideoRNG 방법론의 2단계 구조

본 연구는 표면 메시나 물리 기반 재질 모델을 가정하지 않고 텍스트 프롬프트나 단일 이미지로부터 3D 에셋을 생성하는 2단계 접근법을 제시합니다. 사전 학습된 비디오 디퓨전 백본에서 미세 조정된 비디오 생성기가 먼저 카메라 포즈와 조명이 알려진 구조화된 RGBA 턴테이블 시퀀스를 생성합니다.

비디오 VAE 잠재 프레임과 Gaussian 매핑

선택된 턴테이블 프레임의 비디오 VAE 잠재 프레임을 학습된 Neural Network 외형 특성을 가진 수백만 개의 비방향성 Gaussian으로 직접 매핑하는 피드포워드 대형 재구성 모델을 사용합니다. 공유 방향 디코더와 확률적 Gaussian 레이 트레이서를 통해 새로운 시점과 조명 아래에서 복사도(radiance)를 계산합니다.

고주파 외형 보존과 대규모 재구성 최적화

기하학을 학습하는 동안 고주파 외형을 보존하기 위해 깊이 앵커 외형 학습 기법을 도입했습니다. 또한 전경 토큰 선택과 비용 인식 분산 샘플링을 적용하여 수백만 개의 Gaussian 재구성을 실무적으로 처리할 수 있게 만들었습니다.

복잡한 털과 깃털 에셋 생성 결과

털, 깃털, 거미줄과 같이 기존 기하학적 표현으로 표현하기 까다로웠던 복잡한 에셋을 생성할 수 있습니다. 생성된 결과물은 실시간으로 렌더링하고 조명을 재조정하여 실제 장면에 통합할 수 있습니다.

💡 에디터 코멘트

기존 3D 생성 방식이 고정된 조명을 베이킹하던 한계를 넘어, 비디오 디퓨전 백본을 활용해 재조명이 가능한 Neural Network Gaussian 표현 방식을 구현합니다.
