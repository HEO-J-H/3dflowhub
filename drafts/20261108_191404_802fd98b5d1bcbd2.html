Unity 6 에디터 내 직접 배포

Unity 6에서는 외부 도구를 거치지 않고 에디터 인터페이스에서 직접 웹 게임을 Unity Play로 보낼 수 있습니다. 빌드 결과물을 브라우저에서 바로 확인할 수 있어 테스트 주기가 짧아집니다.

Build Profiles 설정 방법

프로젝트의 Build Profiles 창에 접근하여 대상 플랫폼을 Web으로 지정하면 됩니다. 간단한 설정 변경만으로 웹 타겟 빌드와 배포 준비가 완료됩니다.

💡 에디터 코멘트

Unity 6의 Build Profiles 창에서 Web 플랫폼을 선택하면 브라우저 테스트 과정을 단축할 수 있습니다.

❓ 자주 묻는 질문

Q. Unity 6에서 웹 게임 배포는 어디서 하나요?
A. Build Profiles 창을 열고 플랫폼을 Web으로 선택하여 Unity Play로 바로 배포할 수 있습니다.

Q. 이 기능을 사용하면 어떤 점이 좋아지나요?
A. 브라우저에서 빌드 결과물을 테스트하는 과정이 빨라져 검증 속도가 향상됩니다.
