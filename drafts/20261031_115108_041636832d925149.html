한 줄 요약 — Blender의 강력한 백엔드를 기반으로 3ds Max의 쿼드 메뉴와 명령어 패널, 단축키 체계를 그대로 이식한 무료 오픈소스 3D Suite Moritz 0.2 알파 버전이 공개되었습니다.

분류: 3D DCC › 3ds Max › 업데이트·출시

Moritz 프로젝트의 개발 배경

많은 3ds Max 유저들이 Blender를 접하더라도 손에 익은 조작계와 단축키 때문에 적응하지 못하고 포기하는 경우가 많습니다. 이러한 불편함을 해소하기 위해 개발자는 Blender를 기반으로 하되 Max 유저들이 기대하는 방식으로 작동하도록 완전히 재작업한 무료 오픈소스 3D 스위트인 Moritz를 개발했습니다. 현재 초기 알파 0.2 버전이 Windows 환경을 대상으로 공개되어 테스트를 진행하고 있습니다.

3ds Max 스타일의 네비게이션과 단축키

Moritz는 Max 방식의 네비게이션과 W, E, R 이동·회전·크기 조절 단축키를 지원하며 1~5번 키를 통해 서브 오브젝트 레벨을 제어할 수 있습니다. 마우스 우클릭 시 3ds Max와 유사한 쿼드 메뉴가 호출되어 익숙한 작업 흐름을 제공합니다. 기존 Max 유저들이 별도의 키맵핑 변경 없이도 즉시 손에 익은 방식으로 조작할 수 있도록 설계되었습니다.

명령어 패널과 수정자 스택 구조

Create, Modify, Utilities 탭으로 구성된 Command Panel이 포함되어 있으며, 드래그로 생성한 Primitive는 생성 이후에도 파라미터를 계속 수정할 수 있습니다. Editable Poly 기능과 함께 스택 중간에 위치할 수 있는 Edit Poly 수정자를 지원하여 하단 수정자들의 라이브 상태를 유지합니다. Extrude, Chamfer, Connect, Swift Loop, Target Weld, Smart 익스루드(Shift+드래그), 스무딩 그룹 등 Max 고유의 툴 명칭과 기능을 그대로 담고 있습니다.

Blender 코어 엔진과의 결합

인터페이스와 작업 방식은 3ds Max를 지향하지만, 내부적으로는 Blender가 제공하는 강력한 기능들을 온전히 품고 있습니다. Cycles와 EEVEE 렌더링 엔진을 비롯해 스컬프팅, 애니메이션, Geometry Nodes 등의 고급 기능들을 그대로 활용할 수 있습니다. Max의 직관적인 모델링 UX와 Blender의 탄탄한 기능 세트가 결합된 형태입니다.

💡 에디터 코멘트

기존 3ds Max 유저들이 Blender로 전환할 때 가장 큰 걸림돌이었던 인터페이스와 조작계의 이질감을 극복하도록 설계된 실험적인 도구입니다. Blender의 Cycles와 EEVEE 렌더링, Geometry Nodes 등 핵심 기능을 그대로 유지하면서 Max 스타일의 Edit Poly와 스택 구조를 결합했습니다. Max 유저 친화적인 작업 환경을 선호하거나 오픈소스 기반의 커스텀 3D 파이프라인에 관심이 많은 실무자라면 알파 테스트에 참여해 볼 가치가 있습니다. 단, 초기 알파 버전인 만큼 Windows 환경에서 안정성 검증과 피드백 제공을 염두에 두고 도입해야 합니다.

❓ 자주 묻는 질문

Q. Moritz는 어떤 프로그램인가요?
A. Blender를 기반으로 제작되었으나 3ds Max의 쿼드 메뉴, Command Panel, Edit Poly, 단축키 체계를 그대로 구현한 무료 오픈소스 3D 툴입니다.

Q. 현재 어떤 버전이며 어디서 사용할 수 있나요?
A. 현재 초기 알파 0.2 버전이며, Windows 운영체제 환경에서만 사용할 수 있습니다.
