분류: 3D DCC › 3ds Max › 튜토리얼·팁

메뉴 스트립 도킹 Script 개요

3ds Max 메인 UI에서 분리된 메뉴 스트립을 도킹된 다이얼로그 형태로 변환해 주는 유틸리티 스크립트입니다. 작업 중 뜯어져 나온 메뉴 창을 깔끔하게 정리하려는 목적에서 제작되었습니다.

Script 실행 및 사용 방법

제공된 Script를 3ds Max의 Script Editor에 로드한 뒤 Ctrl+E Hotkey로 실행합니다. 실행 후 나타나는 대화 상자에 도킹하려는 다이얼로그의 이름을 직접 입력하는 방식으로 작동합니다.

사용 시 주의 사항

해당 유틸리티를 통해 적용한 도킹 상태는 3ds Max 프로그램을 재시작할 경우 유지되지 않습니다. 따라서 Software를 다시 켤 때마다 Script를 재실행해야 하는 번거로움이 있습니다.

💡 에디터 코멘트

MAXScript를 활용해 3ds Max의 뜯어진 메뉴 창을 메인 UI에 고정하는 방법입니다. 재시작 시 도킹 상태가 유지되지 않는 제약이 있으나 작업 환경을 빠르게 정돈하는 데 도움을 줍니다.

❓ 자주 묻는 질문

Q. 이 Script는 어떻게 실행하나요?
A. Script Editor에 Script를 불러온 후 Ctrl+E Hotkey를 눌러 실행할 수 있습니다.

Q. 프로그램을 껐다 켜도 도킹 상태가 유지되나요?
A. 아니요, 3ds Max를 재시작하면 도킹 상태는 유지되지 않습니다.
