Output Log를 통한 MCP 활동 추적

Unreal Engine의 Output Log 창에서는 현재 실행 중인 MCP 관련 로그를 실시간으로 확인할 수 있습니다. 툴 호출 과정에서 어떤 요청이 오갔는지 추적하여 실패 지점을 정확히 파악할 수 있는 단서를 제공합니다.

MCP Inspector를 활용한 독립적 툴 호출

MCP Inspector는 오픈 표준을 위해 제작된 공식 디버깅 클라이언트입니다. AI 에이전트를 거치지 않고 직접 툴을 나열하고 호출할 수 있어, 에이전트 연동 과정에서 발생하는 변수를 배제하고 테스트할 수 있습니다.

서버와 툴 오류의 명확한 분리 진단

MCP Inspector 환경에서도 툴 호출이 실패한다면 원인은 Prompt가 아니라 툴 자체나 서버 설정에 있습니다. 문제의 원인이 어디에 있는지 신속하게 좁혀 불필요한 디버깅 시간을 줄여줍니다.

💡 에디터 코멘트

AI 에이전트 없이 MCP Inspector를 사용해 툴을 직접 호출하면 Prompt 문제가 아니라 툴이나 서버 자체의 오류인지 단번에 판별할 수 있습니다.

❓ 자주 묻는 질문

Q. MCP Inspector는 무엇인가요?
A. 오픈 MCP 표준을 위해 제공되는 공식 디버깅 클라이언트로, AI 에이전트를 통하지 않고 툴을 직접 호출하여 테스트할 수 있는 도구입니다.

Q. 툴 호출 실패의 원인이 프롬프트인지 툴 자체인지 어떻게 구별하나요?
A. AI 에이전트를 배제한 채 MCP Inspector를 통해 직접 툴을 호출했을 때 실패한다면, Prompt가 아니라 툴이나 서버 설정에 문제가 있는 것입니다.
