분류: Game Engine › Unity › 업데이트·출시

Unity CLI 1.0 정식 버전 기능

Unity CLI 1.0이 베타 단계를 벗어나 정식 출시되었습니다. 이제 실제 Unity 프로젝트 환경 내에서 Terminal을 통해 AI 에이전트가 직접 레벨 환경을 블록아웃하고 코드를 작성·컴파일할 수 있습니다. 에러 검출과 플레이테스트 기능도 Terminal에서 곧바로 수행 가능합니다.

CliCommand 속성을 통한 커스텀 명령어

개발 팀은 [CliCommand] 속성을 활용해 커스텀 명령어를 정의할 수 있습니다. 이를 통해 AI 에이전트가 프로젝트 고유의 컨벤션과 규칙을 정확히 따르도록 제어할 수 있습니다. Claude Code와 Codex 공식 플러그인을 Terminal 환경에 결합하여 활용합니다.

Unity Pipeline API와 브라우저 연동

Unity Pipeline API는 프로듀서, 아티스트, QA 테스터가 브라우저를 통해 팀의 Git repository에 직접 접근할 수 있도록 연결합니다. 로컬에 Unity Editor를 설치하지 않아도 프로덕션 단계의 파이프라인 협업을 지원합니다.

💡 에디터 코멘트

Unity CLI 1.0은 Claude Code나 Codex 같은 AI 에이전트가 Terminal에서 직접 프로젝트를 제어하도록 지원하여 버려지는 Prototype 제작을 줄입니다.

❓ 자주 묻는 질문

Q. Unity CLI 1.0에서 어떤 AI 에이전트를 지원하나요?
A. Claude Code와 Codex 등 공식 Unity 플러그인을 사용하는 AI 에이전트를 지원합니다.

Q. Pipeline API 사용 시 Unity Editor가 반드시 필요한가요?
A. 아니오. 브라우저를 통해 팀의 Git repository와 연결되므로 Editor를 로컬에 설치하지 않아도 됩니다.
