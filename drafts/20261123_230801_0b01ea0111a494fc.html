한 줄 요약 — Maxon이 기존 Maxon One 구독과 분리되어 텍스트와 이미지로 Base 모델, 텍스처, 조각용 메시를 생성하는 AI 구독 상품 Maxon Plus를 출시했습니다.

분류: AI 3D › 3D 생성 AI › 업데이트·출시

Maxon One과 분리된 구독 구조

Maxon Plus는 기존의 Maxon One Suite와 별도로 판매되는 구독형 부가 상품입니다. AI 기능을 원하지 않는 기존 가입자들의 구독료 인상을 막고 원하지 않는 서비스를 강제하지 않기 위한 선택입니다. Maxon 계정이 있다면 기존 Software 라이선스가 없어도 웹 서비스만 별도로 이용할 수 있습니다.

Model Generator와 Texture Generator의 기능

Model Generator는 텍스트 프롬프트나 참조 이미지를 바탕으로 프롭, 배경 오브젝트, 가구 등의 3D Base 모델을 생성합니다. Texture Generator는 기존 모델이나 수작업으로 스컬프팅한 결과물에 텍스처를 입히며 카메라 뷰와 Prompt를 가이드로 활용합니다. 두 도구 모두 웹 앱이나 Cinema 4D 내부에서 직접 구동할 수 있습니다.

ZBrush for iPad와 연동되는 Clay Builder

Clay Builder는 텍스처가 없는 단순한 저폴리곤 Base 메시를 생성하여 서브디비전, DynaMesh, 스컬프팅 작업으로 이어질 수 있게 돕습니다. ZBrush for iPad와 웹 환경에서 작동하며 본격적인 조각 작업 전에 다양한 아이디어를 빠르게 테스트할 수 있습니다.

브라우저 기반 3D 검토 서비스

Maxon Plus 구독에는 AI 모델 생성 도구 외에도 웹 브라우저를 통해 3D 결과물을 검토할 수 있는 기능이 포함됩니다. 아티스트들은 별도의 무거운 설치 과정 없이 클라우드를 통해 에셋을 검토하고 피드백을 주고받을 수 있습니다.

💡 에디터 코멘트

Maxon Plus는 월 구독료 인상 없이 클라우드 기반 AI 기능을 선택적으로 도입하려는 의도로 기존 Maxon One과 완전히 분리되었습니다.

❓ 자주 묻는 질문

Q. Maxon Plus를 이용하려면 반드시 Maxon One이나 Cinema 4D 라이선스가 있어야 하나요?
A. 아니요. Maxon 계정만 있으면 기존 Maxon Software 라이선스를 보유하지 않아도 Maxon Plus의 웹 서비스와 AI 기능을 독립적으로 구매하여 사용할 수 있습니다.

Q. 기존 Maxon One 구독료에 AI 생성 비용이 포함되어 인상되나요?
A. 아닙니다. 클라우드 기반 생성 기능에 발생하는 비용과 AI를 원하지 않는 아티스트들을 존중하기 위해 기존 Suite와 완전히 분리된 별도 구독 상품으로 출시되었습니다.
