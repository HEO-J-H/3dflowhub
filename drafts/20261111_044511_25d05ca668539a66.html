한 줄 요약 — NVIDIA Snapshot은 Kubernetes 환경에서 초기화된 CPU 및 GPU 메모리 상태를 캡처하여 대규모 언어 모델 추론 복구 시간을 수초 내로 단축하는 오픈소스 체크포인트 및 복구 시스템입니다.

분류: AI 3D › NVIDIA DSX › 업데이트·출시

NVIDIA Snapshot의 체크포인트 및 복구 매커니즘

NVIDIA Snapshot은 쿠버네티스 커스텀 리소스를 통해 GPU Pod의 체크포인트와 복구 작업을 수행합니다. 이미 실행 중인 Pod를 대상으로 PodSnapshot을 생성하거나, 준비되는 즉시 캡처하는 SnapshotJob을 활용하여 워크로드를 휴대 가능한 아티팩트로 저장합니다. 이를 통해 모델 가중치 로딩과 컴파일, 그래프 캡처 과정을 생략하고 동일한 Driver와 GPU 모델이 장착된 노드에서 즉시 재시작할 수 있습니다.

추론 복구 속도와 벤치마크 성능

다양한 설정에서 테스트한 결과, Snapshot 아티팩트를 이용한 복구는 추론 복제본을 3.6초에서 42.7초 사이에 온라인 상태로 전환합니다. 이는 몇 분씩 소요되는 콜드 스타트와 비교했을 때 최대 8배에서 36배 빠른 속도입니다. 대규모 모델에서 1TB에 달하는 체크포인트를 다룰 때도 조합된 체크포인트 및 복구 소요 시간은 단일 콜드 스타트보다 짧게 측정되었습니다.

대규모 텐서 및 데이터 병렬 처리 지원

이 시스템은 8개의 GPU 전반에 걸쳐 최대 1TB 규모의 체크포인트를 지원하며 텐서 병렬성, 데이터 및 전문가 병렬성, 디코드 컨텍스트 병렬성을 활용하는 멀티 GPU 워크로드를 소화합니다. vLLM, SGLang, NVIDIA TensorRT LLM을 위한 즉시 사용 가능한 예제들이 저장소에 마련되어 있습니다.

💡 에디터 코멘트

NVIDIA B200 GPU 환경에서 VAST NFS 스토리지를 사용할 때, 전체 복구 시간의 대부분인 18~29초가 GPU 상태 복원에 소요되며 CRIU 기반 CPU 프로세스 복원은 4.2~10.8초가 걸립니다.
