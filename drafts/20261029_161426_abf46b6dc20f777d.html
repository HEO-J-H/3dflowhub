한 줄 요약 — Godot 4.8 beta 2가 출시되어 150여 건의 리그레션 수정과 기능 안정화 작업을 거쳤습니다.

분류: Game Engine › Godot › 업데이트·출시

베타 2 주요 업데이트 및 버그 수정

Godot 4.8 beta 1 이후 약 2주 동안 개발팀은 150여 건에 달하는 리그레션을 감지하고 해결하는 데 주력했습니다. 이번 Release는 기능이 완전히 완성된 피처 컴플리트(feature-complete) 단계이므로 새로운 기능보다는 안정성 향상에 초점을 맞추고 있습니다. 애니메이션, 에디터, GDScript, 렌더링 등 다양한 영역에서 안정화 작업이 이루어졌습니다.

C# 및 빌드 시스템 변경 사항

C# 지원과 관련하여 GodotSharp Debug 빌드에서 최적화(Optimize) 옵션이 활성화되었습니다. 또한 빌드 시스템의 CI 환경에서 최소 Python 요구 버전이 3.9에서 3.10으로 상향 조정되었습니다. .NET 빌드의 경우 최소 지원 버전이 .NET 8에서 .NET 10으로 변경되어 개발 환경 업그레이드가 필요합니다.

에디터 및 렌더링 개선

애니메이션 베지어 트랙의 박스 스케일링 시 잘못된 실행 취소 데이터가 생성되던 문제가 수정되었습니다. 렌더링 부문에서는 호환성(Compatibility) 모드에서 곱셈 블렌딩(multiply blending)이 너무 어둡게 표시되던 버그가 해결되었습니다. Particle의 각도 기본 곡선 범위가 [-1, 1]로 변경되어 세밀한 제어가 가능해졌습니다.

다양한 플랫폼 지원 및 다운로드

Godot 4.8 beta 2는 Linux, macOS, Windows 환경을 위한 표준 및 .NET 빌드를 제공합니다. 웹 에디터, XR 에디터, 안드로이드 에디터 등 다양한 플랫폼 환경에서도 테스트를 진행할 수 있습니다. 안드로이드 프리릴리스 빌드 이용을 원할 경우 별도의 테스팅 그룹 가입 신청을 통해 접근할 수 있습니다.

💡 에디터 코멘트

Godot 4.8 버전은 기능 동결 단계에 접어들어 새로운 대형 기능 추가보다는 안정성과 버그 수정에 집중하고 있습니다. 실무 프로젝트를 진행 중인 개발자라면 이번 베타 버전을 통해 기존 이슈가 해결되었는지 테스트하고 빌드 안정성을 검증해 볼 필요가 있습니다. 특히 C# 및 .NET 10 환경을 사용하는 프로젝트에서는 빌드 옵션과 최소 요구 사항 변화에 주의를 기울여야 합니다. 프로덕션 환경 도입 전 반드시 백업 후 테스트하는 것을 권장합니다.

❓ 자주 묻는 질문

Q. Godot 4.8 beta 2에서 가장 중점적으로 다뤄진 부분은 무엇인가요?
A. 새로운 기능 추가보다는 150여 건에 달하는 리그레션 수정과 전반적인 안정성 확보에 집중했습니다.

Q. .NET 빌드를 사용할 때 주의할 점은 무엇인가요?
A. .NET 빌드(.NET 모노 포함)는 이제 .NET 10.0 이상이 필요하며 최소 지원 버전이 .NET 8에서 10으로 변경되었습니다.
