강화학습에서 분산 롤아웃 인프라가 필요한 이유

강화학습은 보상을 사용하여 모델이 문제를 해결하고 작업을 더 성공적으로 완료하도록 훈련합니다. 추론 과정에서 작업자는 모델 출력, 작업, 환경 상호작용의 시퀀스인 롤아웃을 생성하며, 학습이 확장됨에 따라 중복 연산과 느린 롤아웃이 발생할 수 있습니다.

강화학습 훈련을 제한하는 세 가지 제약 조건

롤아웃 완료 시간, 반복되는 컨텍스트, 그리고 모델 가중치의 최신성 유지 여부가 학습 효율을 결정합니다. 코딩 에이전트의 저장소 탐색이나 반복적인 Prompt 처리는 GPU 용량을 낭비하게 만드는 주요 원인입니다.

NVIDIA Dynamo 아키텍처와 라우팅 메커니즘

Dynamo는 롤아웃 오케스트레이션과 추론 작업자 사이에 위치하여 요청을 적절한 용량으로 라우팅합니다. KV 인식 라우팅은 캐시 재사용과 작업자 부하를 균형 있게 조절하여 중복 Prompt 연산을 줄입니다.

ModelExpress를 통한 효율적인 가중치 분산

ModelExpress는 압축된 델타 업데이트를 전송하고 GPU 메모리에 이미 상주하는 가중치를 재사용하여 가중치 배포 속도를 가속화합니다. 이를 통해 학습 알고리즘의 요구사항에 맞춰 작업자가 최신 가중치를 안정적으로 수신할 수 있습니다.

장애 복구 메커니즘과 오픈소스 통합

Dynamo는 작업자 장애를 감지하고 요청을 정상 용량으로 재라우팅하며 체크포인트와 델타 로딩을 통해 대체 작업자가 따라잡을 수 있도록 지원합니다. 또한 verl, NeMo RL, Slime, prime-rl 등 기존 강화학습 스택과 연동됩니다.
