대규모 도시 씬 렌더링의 성능 병목 현상

3D Gaussian Splatting은 실시간 렌더링 성능 덕분에 자율주행 Simulator와 생성형 월드 모델에서 널리 쓰이고 있습니다. 하지만 대규모 도시 씬을 처리할 때 스크린 타일 간의 불균형한 작업 부하로 인해 심각한 SM 레벨의 부하 불균형이 발생합니다. 이로 인해 긴 실행 테일이 형성되며, 소수의 복잡한 타일을 처리하는 동안 대부분의 스트리밍 멀티프로세서가 유휴 상태로 남게 됩니다.

Software 기반 GPU 스케줄링 접근법

연구진은 재학습이나 특수 하드웨어 없이 실행 테일을 줄이는 Software 정의 GPU 스케줄링 방식을 제안합니다. 영구 커널을 활용하여 무거운 타일을 먼저 스케줄링하고, 여러 CTA에 걸쳐 이상치 타일을 선택적으로 청크 처리합니다. 기존 렌더링 Pipeline 이미 사용 가능한 타일 통계를 활용해 가벼운 프레임별 정책으로 청크 시기와 규모를 결정합니다.

알파 블렌딩 성능 향상 결과

기존 알파 블렌딩 공식을 그대로 유지하면서도 대규모 도시 씬 기준 평균 2.93배의 가속을 달성했습니다. 특히 부하 불균형이 심한 프레임에서는 최대 5.6배까지 속도가 향상되는 결과를 보여줍니다. 다양한 3DGS 변형 모델과 독립적으로 결합하여 적용할 수 있다는 점이 특징입니다.

💡 에디터 코멘트

대규모 도시 씬에서 알파 블렌딩 속도가 최대 2.93배, 가장 불균형한 프레임에서는 최대 5.6배까지 빨라집니다. 별도의 하드웨어 변경이나 모델 재학습 없이 기존 3DGS 변형 전반에 적용할 수 있습니다.
