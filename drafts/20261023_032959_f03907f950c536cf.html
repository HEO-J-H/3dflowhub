한 줄 요약 — 범용 AI 에이전트와 nnInteractive 모델을 결합해 텍스트 명령만으로 3D 볼륨 마스크 어노테이션을 자동 수행하는 오픈소스 도구가 공개되었습니다.

분류: AI 3D › 로보틱스·월드모델 › 연구·논문

nnInteractive Agent의 개요와 배경

기존의 nnInteractive 같은 인터랙티브 3D 세그멘테이션 모델은 점, 스크리블, 박스 등의 공간 Prompt를 정확한 볼륨 마스크로 변환해 주지만, 구조물 탐색이나 Prompt 배치 및 결과 검증은 여전히 사람이 직접 수행해야 했습니다. 연구진은 범용 AI 에이전트가 이러한 수동 어노테이션 작업을 추가 학습 없이 완전 자동화할 수 있음을 입증했습니다. 사용자가 자연어로 요청하면 에이전트가 세그멘테이션 대상을 파악하고 위치를 찾아 nnInteractive를 구동합니다.

Model Context Protocol(MCP) 기반 툴 활용

오픈소스로 공개된 nninteractive-agent는 nnInteractive를 Model Context Protocol(MCP) 인터페이스를 통한 툴로 제공합니다. 숙련된 사용자가 Prompt를 구성하는 방식을 인코딩한 스킬을 함께 탑재하고 있어 에이전트의 정확도를 높였습니다. 예를 들어 저작근 세그멘테이션이나 간 병변 개수 세기 같은 복잡한 요청을 처리할 때 에이전트가 직접 코드를 작성해 후보를 찾고 병합된 병산을 분할합니다.

다양한 벤치마크 데이터 셋 성능 평가

인간, 생쥐, 개미를 대상으로 한 CT, MRI, PET, 마이크로 CT 등 14개 이미지와 51개 타겟을 포함한 벤치마크 테스트가 진행되었습니다. Claude Code와 Codex는 자연어 요청만으로 평균 Dice 계수 0.81 및 0.84를 달성했습니다. 타겟의 정확한 위치 정보를 사전에 제공받은 경우에는 두 에이전트 모두 0.85의 성능을 기록하며 오라클 수준의 Prompt 능력을 보여주었습니다.

기존 텍스트 Prompt 3D 모델과의 비교

텍스트 Prompt 기반의 3D 모델인 VoxTell은 표준 방사선학적 타겟 대부분에서 높은 정확도를 보였지만 강건성 측면에서 한계를 드러냈습니다. VoxTell은 일부 타겟에서 빈 마스크를 반환하거나 다리 근육, 발 뼈, 생쥐, 개미 데이터에서 실패하는 양상을 보였습니다. 반면 AI 에이전트 결합 방식은 이러한 복잡하고 이질적인 데이터 셋에서도 안정적인 정확도를 유지했습니다.

💡 에디터 코멘트

의학용 CT나 MRI뿐만 아니라 복잡한 3D 공간 데이터 세그멘테이션 작업에서 인적 병목 현상을 획기적으로 줄여줄 수 있는 연구입니다. Model Context Protocol(MCP)을 활용하여 에이전트가 툴을 직접 호출하고 코드를 작성하는 워크플로는 향후 다양한 3D 에디팅 및 데이터 전처리 파이프라인으로 확장될 잠재력이 큽니다. 대규모 3D 데이터 셋 구축과 라벨링 작업 효율화를 고민하는 테크 실무자라면 주의 깊게 살펴봐야 합니다. 텍스트 Prompt 기반의 기존 3D 모델보다 복잡한 대상(동물 뇌, 뼈 등)에서 훨씬 높은 강건성을 보여주는 점이 실무 적용의 핵심 포인트입니다.

❓ 자주 묻는 질문

Q. nnInteractive Agent는 어떤 방식으로 3D 이미지 어노테이션을 수행하나요?
A. 사용자의 자연어 요청을 분석한 뒤, Model Context Protocol(MCP)을 통해 nnInteractive를 툴로 호출하고 필요시 직접 코드를 작성하여 3D 세그멘테이션 결과를 검증 및 수정합니다.

Q. 기존 3D 세그멘테이션 모델과 비교했을 때의 장점은 무엇인가요?
A. 사람이 개입해 Prompt를 일일이 배치하던 수동 작업을 AI 에이전트가 대체하며, 생쥐나 곤충 브레인 같은 복잡하고 비정형적인 3D 데이터에서도 빈 마스크 오류 없이 강건하게 작동합니다.
