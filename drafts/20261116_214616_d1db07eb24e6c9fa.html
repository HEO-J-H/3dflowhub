한 줄 요약 — Unity CLI와 Pipeline 패키지가 베타를 마치고 1.0 버전으로 정식 출시되어 터미널과 자동화 에이전트 환경을 지원합니다.

분류: Game Engine › Unity › 업데이트·출시

Unity CLI 1.0과 Pipeline 패키지 정식 공개

Unite Tokyo에서 Unity CLI와 com.unity.pipeline 패키지가 정식 1.0 버전으로 전환되었습니다. 터미널을 통해 프로젝트, 빌드 머신, 에이전트 환경에서 Unity 에디터와 모듈을 직접 관리할 수 있습니다.

코딩 에이전트 연동과 자동화 지원

Claude Code, Codex, Grok Build, Google Antigravity 등 공식 플러그인을 지원합니다. unity setup 및 unity skill install 명령어로 에이전트에 필요한 기능을 바로 추가할 수 있습니다.

원격 세션 및 다이얼로그 차단 해결

에디터가 대화상자에서 멈추는 현상을 방지하는 기능이 추가되었습니다. CLI가 에디터가 대기 중인 다이얼로그를 감지하고 응답하여 원격 세션이나 Script가 멈추지 않고 실행됩니다.

일관된 출력과 프로젝트 진단 기능

모든 스트림과 리스팅이 동일한 JSON 형태로 출력되며 명확한 종료 코드를 반환합니다. 또한 unity projects audit 명령어로 프로젝트 감사 리포트를 작성할 수 있습니다.

💡 에디터 코멘트

버전 1.0에서는 unity setup 명령어로 Claude Code나 Codex 같은 외부 코딩 에이전트 플러그인을 한 번에 설치할 수 있어 빌드 및 에디터 제어 작업이 편해집니다.

❓ 자주 묻는 질문

Q. Unity CLI 1.0을 사용하려면 어떻게 설치하나요?
A. 최신 버전의 Unity Hub를 사용 중이라면 이미 설치되어 있습니다. 터미널에서 관련 명령어를 통해 바로 활용할 수 있습니다.

Q. 어떤 코딩 에이전트들과 연동되나요?
A. Claude Code, Codex, Grok Build, Google Antigravity를 공식 지원하며 unity setup 명령어로 간편하게 설정할 수 있습니다.
