gds-diag 도구의 개요와 역할

gds-diag는 GPUDirect Storage(GDS) 환경을 평가하고 문제를 식별하며 개선 사항을 제안하는 오픈소스 명령줄 유틸리티입니다. 이 도구는 엔드투엔드 점검, 설치 전 유효성 검사, 설치 후 검증, 컨테이너 환경 및 특정 마운트 지점에 대한 심층 진단 기능을 제공합니다. 관리자가 문제를 쉽게 해결할 수 있도록 FAIL, WARN, INFO, PASS 등의 상태 배지와 함께 설명 및 완화 계획을 제시합니다.

자연어 인터페이스를 지원하는 AI 에이전트 스킬

gds-diag는 명령줄 도구 외에도 자연어 인터페이스와 오케스트레이션 레이어를 추가하는 선택적 에이전트 스킬을 함께 제공합니다. 이 스킬은 사용자의 의도를 해석하고 적절한 하위 명령을 호출하여 다단계 진단 워크플로를 조율합니다. 모델 기반 추론을 통해 진단 결과를 해석하고 시스템 컨텍스트를 적용하여 적절한 수정 조치를 제안하거나 수행할 수 있습니다.

다운로드 및 시스템 요구사항

gds-diag를 사용하려면 Python 3.8 이상이 설치된 Linux 시스템이 필요합니다. GPUDirect Storage 자체는 NVIDIA 데이터센터용 GPU와 NVIDIA CUDA Toolkit 12.2 이상을 요구하지만, 진단 도구인 gds-diag 실행 시에는 이러한 항목들이 직접적인 종속성으로 작용하지 않습니다. 이 도구는 NVIDIA Magnum IO GitHub 리포지토리를 통해 오픈소스로 배포됩니다.

설치 및 실행 방법

사용자는 git clone https://github.com/NVIDIA/MagnumIO.git 명령어로 리포지토리를 복제하여 진단 도구를 설치할 수 있습니다. 명령줄 인터페이스를 통해 최소한의 종속성으로 GDS 배포를 진단하거나, Claude 또는 Codex와 같은 코딩 어시스턴트에서 gds-diag 디렉토리를 열어 자연어 진단 기능을 활용할 수 있습니다.

❓ 자주 묻는 질문

Q. gds-diag 실행을 위해 NVIDIA GPU와 CUDA Toolkit이 반드시 로컬에 설치되어 있어야 하나요?
A. GPUDirect Storage 작동에는 NVIDIA 데이터센터용 GPU와 CUDA Toolkit 12.2 이상이 필요하지만, 진단 도구인 gds-diag 자체는 Python 3.8 이상의 Linux 환경에서 별도의 무거운 종속성 없이 실행할 수 있습니다.

Q. gds-diag는 어디서 다운로드할 수 있나요?
A. NVIDIA Magnum IO 공식 GitHub 리포지토리(https://github.com/NVIDIA/MagnumIO.git)를 클론하여 gds-diag 디렉토리에서 이용할 수 있습니다.
