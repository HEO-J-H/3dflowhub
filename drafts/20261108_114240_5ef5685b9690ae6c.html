한 줄 요약 — NVIDIA DSX OS는 가속화된 Kubernetes 인프라의 설정, 인증, 유지보수를 자동화하는 오픈소스 Software 계층을 제공합니다.

분류: AI 3D › NVIDIA DSX › 업데이트·출시

NVIDIA AI Cluster Runtime 구성

AICR은 네트워킹, 스토리지, Driver 등 주요 구성 요소의 버전이 고정된 레시피를 정의합니다. Argo CD, Flux, Helm 같은 배포 도구에서 사용할 수 있는 번들 형태로 렌더링되어 재현 가능한 기반을 제공합니다.

NVIDIA Cluster Readiness Engine 검증

NVCRE는 NCCL 통신 테스트와 AI 학습 워크로드를 실행하여 프로덕션 환경의 가동 준비 상태를 검증합니다. 성능 임계값을 충족하는지 확인하고 실패한 노드 그룹을 분할하여 문제가 있는 노드를 찾아냅니다.

NVSentinel을 통한 상태 모니터링

NVSentinel은 GPU, 노드, 네트워크 상태 신호를 지속적으로 모니터링하여 노드 조건을 게시합니다. 결함이 감지되면 노드를 격리하고 워크로드를 드레인한 뒤 조치를 취하며, NVCRE를 통해 재검증을 트리거할 수 있습니다.

💡 에디터 코멘트

NVIDIA AI Cluster Runtime(AICR)은 버전이 고정된 구성 레시피를 정의하여 대규모 분산 학습 환경에서 Driver 업그레이드나 노드 교체 후 발생하는 인프라 구성 편차를 방지합니다.
