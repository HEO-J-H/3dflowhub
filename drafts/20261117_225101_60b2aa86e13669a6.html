한 줄 요약 — Unity 7이 ECS for All, Unity CLI, Asset Library 플러그인 등으로 개발 속도와 성능을 크게 끌어올렸다고 발표했습니다.

분류: Game Engine › Unity › 업계 소식

Unity 7 핵심 테마

키노트는 Unity 7이 세 가지 테마—전 장치에서의 높은 성능, 빠른 제작, 크리에이터 지원—를 중심으로 설계됐다고 강조했습니다. ECS for All은 기존 GameObject와 Entity 간 호환성을 높이고, 그래픽스는 기본적으로 스케일러블하게 제공됩니다.

ECS for All 성능 시연

Sangbae Nam은 5,000개의 우주선 데모에서 GameObject 버전은 프레임률이 급락했지만, ECS for All 버전은 일정한 프레임률을 유지했습니다. Unity 7.0에서는 Inspector에서 Entity 데이터를 직접 확인·편집할 수 있습니다.

Unity CLI와 공식 플러그인

Unity CLI는 1.0 버전이 오늘 공개됐으며, 수백만 개발자가 이미 빌드 자동화에 활용하고 있습니다. Claude, Codex, Google Antigravity, Grok용 공식 플러그인이 함께 제공돼 AI 기반 코딩 에이전트를 바로 에디터에 연결할 수 있습니다.

Asset Library 플러그인

새로운 Asset Library 플러그인을 통해 Unity Asset Store를 에디터 내부에서 검색하고 바로 가져올 수 있습니다. 현재 Asset Store에 등록된 수천 개 에셋을 실시간으로 탐색할 수 있어 작업 흐름이 끊기지 않습니다.

Unity Fellowship 지원 프로그램

Unity Fellowship은 매년 10개 인디 팀에 현금 5만 달러와 전용 리소스를 제공하며, 수익 배분이나 회수 요구가 없습니다. 이번 발표에서는 첫 번째 수혜 팀이 공개되었습니다.

💡 에디터 코멘트

ECS for All은 5,000개의 우주선 데모에서 기존 GameObject 기반보다 프레임률을 일정하게 유지해 약 60% 이상의 성능 향상을 보여줍니다. 대규모 오브젝트를 다루는 모바일 게임이나 시뮬레이션 프로젝트에 즉시 적용해 볼 수 있습니다.
