NVIDIA OpenShell 런타임과 AI 에이전트 보안 제어

NVIDIA OpenShell은 NVIDIA Open Agent Safety Platform의 핵심 구성 요소입니다. 샌드박스 실행 환경과 정책 기반 제어를 제공하여 민감한 데이터를 보호하고 엔터프라이즈 도구 접근을 관리합니다. 현대자동차그룹은 NVIDIA NemoClaw 블루프린트와 OpenShell 런타임을 탐색 중이며 AIM Intelligence는 Starfort 플랫폼을 연동하고 있습니다.

AIM Intelligence의 Starfort 플랫폼 통합

한국의 AI 보안 기업인 AIM Intelligence는 Starfort 에이전트 제어 플랫폼을 NVIDIA OpenShell과 통합하고 있습니다. OpenShell의 런타임 접근 제어와 Starfort의 악성 명령어 탐지 및 데이터 유출 방지 기능을 결합하는 것이 목적입니다. 공공 에너지 부문을 대상으로 한 사전 개념 증명도 검토 중입니다.

LG AI연구원의 K-EXAONE-2.5 API 공개

모델 측면에서는 LG AI연구원이 NVIDIA Nemotron 데이터셋을 활용해 개발한 K-EXAONE-2.5의 API 접근을 개방합니다. 여기에는 Nemotron-Personas-Korea 데이터셋이 포함됩니다. 공식 한국 통계에 기반한 700만 개의 합성 한국인 페르소나 데이터셋으로 개발자들이 한국적 맥락에서 학습 데이터와 평가를 구축할 수 있게 지원합니다.

💡 에디터 코멘트

NVIDIA OpenShell은 샌드박스 실행과 정책 기반 제어를 통해 자율형 에이전트의 데이터 유출을 방지합니다. 엔터프라이즈 환경에서 자율 에이전트 구축 시 보안 검토 시간을 줄여줍니다.
