한 줄 요약 — Adobe가 출시한 Substance 3D Painter 12.2는 케이지 페인팅 등 텍스처링 작업 흐름을 간소화하는 기능을 추가했다.

분류: 3D DCC › Substance 3D › 업데이트·출시

케이지 페인팅 소개

Substance 3D Painter 12.2는 케이지 페인팅 기능을 도입해 Baking 시 투사 거리를 직접 제어한다. 아티스트는 브러시로 픽셀 단위까지 케이지 거리를 페인팅하거나 Polygon Fill을 이용해 서브 오브젝트 전체를 조정할 수 있다. 이를 통해 케이지가 너무 가깝거나 멀어 발생하는 디테일 손실을 사전에 방지한다.

Polygon Fill 선택 모드

Polygon Fill에 새롭게 세 가지 선택 모드가 추가되었다. Rectangular Marquee는 드래그로 영역을 지정하고, Polygon Loop는 연속된 면 루프를 선택한다. Partial Polygon Loop는 전체 루프가 과도할 때 일부만 선택할 수 있게 해준다. 또한 Visible Polygons Only 옵션은 반대쪽 면을 건드리지 않도록 해 밀집 메시에 대한 마스크 작업을 안전하게 만든다.

Texture Set Highlighting

새로운 Texture Set Highlighting 기능은 텍스처 세트를 마우스 오버하면 해당 지오메트리를 강조한다. Ctrl/Cmd + Alt 키와 함께 모델을 가리키면 해당 파트가 속한 텍스처 세트를 즉시 확인할 수 있다. 이는 복잡한 프로젝트에서 머티리얼 구성을 빠르게 파악하는 데 큰 도움이 된다.

💡 에디터 코멘트

텍스처 아티스트는 이제 케이지 거리를 모델에 직접 페인팅해 Baking 오류를 사전에 확인할 수 있어 반복적인 Baking 과정을 크게 줄일 수 있다. Polygon Fill의 새로운 선택 모드는 복잡한 메시에 대한 마스크 작업을 직관적으로 만들며, 특히 겹치는 파트가 많은 모델에서 유용하다. Texture Set Highlighting은 다수의 머티리얼이 적용된 캐릭터나 소품을 빠르게 파악하게 해 프로젝트 초기 탐색 시간을 단축한다. 투명 소재의 실시간 미리보기가 개선된 Order Independent Transparency은 유리·얼음 등 저투명도 머티리얼 작업 시 정확한 시각적 피드백을 제공한다. 이러한 기능들은 실시간 피드백을 중시하는 게임 및 디지털 아트 파이프라인에 특히 큰 도움이 된다.
