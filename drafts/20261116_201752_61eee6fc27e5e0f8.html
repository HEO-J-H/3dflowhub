한 줄 요약 — Gameloft Brisbane이 Unreal Engine 5를 활용해 인기 TV 애니메이션 Bluey의 2D 그래픽을 3D 비디오 게임으로 구현한 제작 과정입니다.

분류: Game Engine › Unreal Engine › 작품·제작 사례

Gameloft Brisbane의 Bluey Happy Snaps 개발 배경

Gameloft Brisbane 개발팀은 전 세계적으로 사랑받는 TV 애니메이션 Bluey의 독창적인 2D 미술 스타일을 게임 속에서 그대로 살려내기 위한 프로젝트를 진행했습니다. 2D 특유의 선화와 색감 유지하면서도 인터랙티브한 3D 공간을 구축하는 것이 핵심 목표였습니다.

Unreal Engine 5 애니메이션 도구의 활용

개발팀은 Unreal Engine 5가 제공하는 애니메이션 시스템과 렌더링 기술을 활용해 원작의 느낌을 3D 환경으로 옮겨왔습니다. 캐릭터의 움직임과 표정이 2D 감성을 유지하도록 리깅과 Viewport 설정을 세밀하게 조정했습니다.

2D 비주얼을 3D 게임플레이로 번역하는 기법

단순한 텍스처 매핑을 넘어 카메라 시점에 따른 원근감 처리와 독특한 외곽선 표현을 적용했습니다. 이를 통해 플레이어는 애니메이션 에피소드 안에 직접 들어와 있는 듯한 경험을 누릴 수 있습니다.

💡 에디터 코멘트

Unreal Engine 5의 애니메이션 기능과 렌더링 기법을 사용하여 전통적인 2D 외곽선과 평면적인 느낌을 3D 공간에서 완벽히 재현했습니다. 2D IP를 기반으로 입체적인 게임을 기획하는 프로젝트에서 Shader와 렌더링 파이프라인을 구성할 때 참고할 만한 사례입니다.
