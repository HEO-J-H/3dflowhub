한 줄 요약 — Unity Spark를 통해 브라우저 에디터 안에서 프로젝트 맞춤형 커스텀 툴을 실시간으로 제작할 수 있는 기능이 공개되었습니다.

분류: Game Engine › Unity › 업데이트·출시

브라우저 기반 커스텀 툴 제작

Unity Spark는 브라우저 에디터 환경에서 프로젝트의 요구사항에 딱 맞는 맞춤형 툴을 직접 만들 수 있는 기능을 제공합니다. 외부 프로그램 전환 없이 작업 공간 내부에서 필요한 컨트롤을 즉시 구성할 수 있습니다.

레벨 페인터와 비주얼 무드 보드

프롭을 정확하게 배치하는 탑다운 레벨 페인터부터 즉각적인 라이팅 조정을 돕는 비주얼 무드 보드까지 시각적이고 프로젝트 중심적인 컨트롤을 실시간으로 생성합니다. 복잡한 작업 단계마다 알맞은 제어가 가능해집니다.

정밀 제어를 위한 에디터 전환

사용자가 완전한 정밀도가 필요할 때 커스텀 툴 인터페이스에서 곧바로 Unity Spark Editor 컨트롤로 매끄럽게 전환할 수 있습니다. 이를 통해 복잡한 프로젝트 레벨에서도 작업 흐름을 유지합니다.

💡 에디터 코멘트

브라우저 환경에서 탑다운 레벨 페인터와 비주얼 무드 보드 같은 프로젝트 전용 컨트롤을 즉시 생성하여 레벨 디자인과 라이팅 조정 작업을 간소화합니다.

Q. Unity Spark는 어떤 환경에서 작동하나요?
A. 브라우저 에디터 내부에서 프로젝트 맞춤형 툴을 직접 제작하고 실행할 수 있도록 지원합니다.

Q. 어떤 종류의 커스텀 툴을 만들 수 있나요?
A. 정확한 프롭 배치를 위한 탑다운 레벨 페인터나 실시간 라이팅 조정을 위한 비주얼 무드 보드 등을 시각적으로 구성할 수 있습니다.
