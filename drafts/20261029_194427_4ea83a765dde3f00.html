한 줄 요약 — Linden Lab이 23년 된 가상 세계 Second Life에 Luau 언어와 Visual Studio Code 통합 기능을 도입하여 현대적인 게임 개발 플랫폼으로 도약하고자 한다.

분류: Game Engine › 기타 엔진 › 업데이트·출시

Second Life의 현대적 게임 플랫폼 전환

23년 역사를 지닌 지속형 가상 세계 Second Life가 현대적인 게임 개발자들에게 더욱 다가서기 위한 대규모 개편을 추진하고 있습니다. 월간 활성 사용자 700만 명 규모를 자랑하는 이 플랫폼은 개발 접근성을 높이기 위해 새로운 기술 스택을 도입 중입니다. 특히 Roblox에서 쓰이는 고성능 Luau 언어 기반의 Script 시스템을 구축하고 있습니다.

Luau 및 Visual Studio Code 통합

Linden Lab은 SLua 시스템을 통해 Roblox 등 Lua 기반 환경에 익숙한 개발자들이 쉽게 적응할 수 있도록 지원합니다. 또한 Visual Studio Code 통합과 라이브 멀티플레이어 환경 내 직접 테스트 워크플로를 제공합니다. 이를 통해 개발자는 서버 간 객체 이동이나 복잡한 상태 유지 작업을 더욱 안정적으로 수행할 수 있습니다.

기존 Linden Scripting Language와의 공존

이번 업데이트가 기존의 오랜 역사 가진 Linden Scripting Language를 완전히 대체하거나 전통적인 게임 엔진으로 바꾸는 것은 아닙니다. 기존 LSL과 새로운 Lua Script는 동일한 객체 안에서도 공존할 수 있도록 설계되었습니다. 초기 테스트 결과 크리에이터들은 더 높은 메모리 제한과 적은 Script로 더 많은 기능을 구현할 수 있다는 긍정적인 피드백을 보였습니다.

다양한 대안 중 Luau가 채택된 이유

Linden Lab의 제품 담당 수석 부사장인 Anya Kanevsky에 따르면 C#, JavaScript, WebAssembly 등 다양한 대안이 검토되었습니다. 그러나 수천 개의 지속형 Script가 안전하게 실행되어야 하고, 일시 중지와 재개, 상태 보존, 서버 간 객체 이동 등 Second Life만의 독특한 기술적 요구사항을 충족하는 최적의 언어로 Luau가 선택되었습니다.

💡 에디터 코멘트

Second Life는 오랜 기간 독자적인 크리에이터 경제를 유지해 왔으나, 구형 Script 언어로 인해 현대 게임 개발자들에게 진입 장벽이 있었습니다. Roblox 등에서 검증된 고성능 Luau 언어와 Visual Studio Code 연동이 도입되면서 대규모 실시간 상호작용 경험을 제작하려는 개발자들의 접근성이 크게 개선될 것입니다. 기존 LSL Script와의 공존을 지원하므로 레거시 자산을 유지하면서도 메모리 효율과 성능을 높일 수 있는 실무적 전환점이 됩니다. 웹 기반 가상 공간이나 메타버스 콘텐츠를 기획하는 실무자라면 이번 Script 생태계 개편을 주목할 필요가 있습니다.

❓ 자주 묻는 질문

Q. Second Life가 도입한 새로운 Script 언어는 무엇인가요?
A. Roblox의 고성능 Luau 언어를 기반으로 한 SLua 시스템을 도입하여 현대적인 스크립팅 환경을 제공합니다.

Q. 기존에 사용하던 Linden Scripting Language는 더 이상 사용할 수 없나요?
A. 아닙니다. 기존 LSL은 계속 지원되며, 새로운 Lua Script와 동일한 객체 안에서도 서로 공존하여 작동할 수 있습니다.
