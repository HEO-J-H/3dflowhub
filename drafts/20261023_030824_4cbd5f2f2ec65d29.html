한 줄 요약 — 대형 언어 모델과 에이전트 워크플로를 활용하여 자연어 Prompt를 도메인 특화 구조 데이터 모델로 변환하는 초기 단계 구조 설계 개념 증명 연구가 발표되었습니다.

분류: AI 3D › 3D 생성 AI › 연구·논문

연구 개요 및 배경

최근 대형 언어 모델과 에이전트 워크플로의 발전은 디자인 의도를 구조적 모델로 번역하는 새로운 초기 단계 구조 설계 패러다임을 제시하고 있습니다. 기존의 텍스트 투 3D 접근법은 시각적이고 메시 기반의 기하학적 모델을 생성하는 데 그쳤으나, 실제 구조 설계는 도메인 특화된 기하학적 배치와 의미론적으로 풍부한 데이터 타입을 요구합니다. 본 논문은 이러한 한계를 극복하기 위해 Prompt 투 구조 생성 연구를 다룹니다.

COMPAS API와 MCP 연동 방식

본 연구에서 제안하는 워크플로는 AI 에이전트를 COMPAS 기반 구조 모델링 API와 연결하는 방식을 채택하고 있습니다. 이를 위해 Model Context Protocol(MCP) 서버를 활용하여 제어된 모델링 작업을 수행합니다. 에이전트는 명시적인 건축 요소로 구성된 그래프 기반 구조 데이터 모델을 직접 생성하고 수정할 수 있습니다.

반복적이고 편집 가능한 설계 시퀀스

생성된 결과물은 검사, 수정, 직렬화가 가능하며 하위 AEC 워크플로와 손쉽게 연동될 수 있습니다. 연구진은 선택된 Prompt 투 구조 예시와 점진적이고 편집 가능한 설계 시퀀스를 통해 접근 방식을 시연했습니다. 이는 전형적인 반복적 구조 설계 워크플로와 유사한 형태를 띱니다.

향후 전망 및 IASS 2026 채택

본 연구 결과는 아직 초기 단계에 머물러 있지만, 자연어와 에이전트 워크플로, 도메인 특화 구조 데이터 구조를 결합할 수 있는 가능성을 명확히 보여줍니다. 이는 AI 보조 구조 공동 설계로 나아가는 중요한 첫걸음으로 평가받고 있습니다. 관련 논문은 이탈리아 토리노에서 개최되는 International Association for Shell and Spatial Structures(IASS) Annual Symposium 2026에 채택되었습니다.

💡 에디터 코멘트

본 연구는 단순한 시각적 텍스트 투 3D 생성에서 나아가, 건축 및 엔지니어링(AEC) 분야에서 요구하는 정밀하고 의미론적인 데이터 구조를 AI가 다룰 수 있는 가능성을 보여줍니다. Model Context Protocol(MCP) 서버를 활용해 외부 구조 모델링 API와 연동함으로써 실무에서 활용 가능한 반복적이고 수정 가능한 설계 시퀀스의 초석을 다졌습니다. 향후 3D 실무 에이전트 개발이나 파라메트릭 디자인 자동화를 연구하는 개발자 및 엔지니어들이 주목해야 할 연구입니다.

❓ 자주 묻는 질문

Q. 이 연구에서 사용된 핵심 기술은 무엇인가요?
A. 대형 언어 모델 기반의 AI 에이전트와 Model Context Protocol(MCP) 서버를 통해 연결된 COMPAS 기반 구조 모델링 API를 활용합니다.

Q. 기존 텍스트 투 3D 기술과 어떤 차이가 있나요?
A. 기존 기술이 시각적이고 단순한 메시 기반 모델 생성에 집중했다면, 본 연구는 건축 및 엔지니어링 실무에 필요한 도메인 특화 구조 데이터와 명시적인 빌딩 요소를 다룹니다.
