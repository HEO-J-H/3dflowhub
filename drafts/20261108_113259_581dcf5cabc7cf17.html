한 줄 요약 — NVIDIA가 대규모 언어 모델 강화학습 후학습 과정에서 훈련 GPU와 추론 GPU 사이의 모델 가중치 전송 속도를 최대 5.7배 높여주는 Reshard collective 기술을 발표했습니다.

강화학습 웨이트 리핏과 통신 병목

강화학습 후학습 단계에서는 현재 정책 모델로 추론을 실행해 훈련 궤적을 실시간으로 생성합니다. 훈련과 추론을 분리된 GPU 자원에서 병렬로 수행할 때, 훈련 GPU에서 갱신된 모델 가중치를 추론 GPU로 주기적으로 동기화하는 과정을 리핏이라고 부릅니다. 대형 모델의 경우 리핏 한 번에 전송해야 하는 데이터 페이로드가 최대 10TB에 달해 통신 병목이 발생합니다.

기존 Gather-and-Broadcast 방식의 한계

기존 리핏 구현 방식은 훈련 GPU들이 로컬 샤드를 모아 전체 파라미터를 재구성한 뒤 추론 GPU 전체에 브로드캐스트하는 구조를 사용합니다. 이 방식은 추론 GPU가 자신의 로컬 레이아웃에 필요한 샤드 외에도 전체 파라미터를 수신해야 하므로 불필요한 네트워크 트래픽을 유발합니다. 모델 규모가 커질수록 이 중간 표현 방식은 통신 효율을 크게 떨어뜨립니다.

DTensor 간 최소 데이터 전송 Reshard Collective

새롭게 도입된 Reshard collective는 리핏 과정을 DTensor 간 전송으로 재구성하여 임의의 소스 레이아웃과 타겟 레이아웃 사이에서 이론적 최솟값에 해당하는 데이터만 이동시킵니다. NCCL M2N Reshard는 정확한 샤드 교차점을 도출하고 NVLink 도메인 레플리카를 그룹화하여 중복되는 네트워크 전송을 제거합니다. 이를 통해 대형 모델 분산 환경에서 전송 시간을 대폭 단축합니다.

NeMo RL 벤치마크 성과와 하이브리드 접근법

NVIDIA DGX H100 및 DGX GB200 시스템에서 진행된 NeMo RL 벤치마크 결과, Reshard 리핏은 기존 방식 대비 2.7배에서 5.7배 속도 향상을 달성했습니다. 전체 페이로드의 대부분을 차지하는 피드포워드 프로젝션 웨이트에는 Reshard를 적용하고, 상대적으로 작은 가중치에는 기존 gather-and-broadcast 방식을 유지하는 하이브리드 방식을 적용해 기능적 커버리지를 보장합니다.
