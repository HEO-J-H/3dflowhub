한 줄 요약 — 메인 화면, 일시정지, 저장 기능이 포함된 옵션, 확인 창을 제공하는 Unreal Engine용 C++ 메뉴 플러그인입니다.

분류: Game Engine › Unreal Engine › 플러그인·스크립트

제공되는 메뉴 구성과 설정 기능

메인 메뉴, 일시정지 메뉴, 그래픽·Audio·컨트롤·게임플레이 설정이 포함된 옵션 화면, 종료 확인 다이얼로그를 포함합니다. 26가지의 설정값이 자동으로 저장되고 불러와집니다.

4가지 기본 시각 테마

Horror, Retro Arcade, Neon Terminal, Fantasy의 4가지 스타일을 제공하며 게임 실행 중에 테마를 실시간으로 전환할 수 있습니다. 9-slice 프레임을 사용하는 텍스처를 교체해 자신만의 커스텀 테마를 만들 수 있습니다.

입력 장치 대응과 연동 방식

키보드, Mouse, 게임패드를 모두 지원하며 입력 장치 변경에 따라 버튼 안내 Prompt가 자동으로 바뀝니다. 모든 설정은 하나의 Data Asset 안에서 관리되며 Blueprint 함수 두 개로 간편하게 호출하거나 포함된 GameMode를 사용해 바로 적용할 수 있습니다.

💡 에디터 코멘트

C++로 구현된 26가지 그래픽·Audio 설정 저장 기능과 Data Asset 기반 제어를 제공하여 Prototype UI 제작 시간을 줄여줍니다.
