한 줄 요약 — 암스테르담에서 개최된 BCON26 컨퍼런스에서 블렌더 개발팀은 안드로이드 포팅, OpenPBR 머티리얼, 지오메트리 노드 기반 물리 시뮬레이션 등 핵심 로드맵을 공개했습니다.

분류: 3D DCC › Blender 업데이트

안드로이드용 Blender 포팅 프로젝트

Jonas Holzman은 Blender를 안드로이드 OS로 포팅하는 여정과 프로젝트의 현재 진행 상황을 공유했습니다. 다양한 사용 사례를 보여주는 데모와 함께 직접 다운로드하여 테스트할 수 있는 데모 APK 빌드가 공개되었습니다. 모바일 환경에서의 3D 작업 가능성을 열어주는 중요한 마일스톤입니다.

차세대 표면 셰이딩 모델 OpenPBR

Sebastian Herholz와 Weizhen Huang은 팀 간 협업을 강화하고 다양한 애플리케이션 간에 일관된 외형을 유지하기 위한 새로운 셰이딩 모델 OpenPBR을 소개했습니다. 현재 구현된 기능과 향후 계획을 공유하며 오픈 피드백 토론을 진행했습니다. 이를 통해 향후 다른 3D 소프트웨어와의 머티리얼 호환성이 크게 향상될 것입니다.

지오메트리 노드로 제어하는 물리 시뮬레이션

Simon Thommes는 블렌더의 새로운 물리 노드가 제공하는 기능들을 상세히 소개했습니다. 이 워크숍에서는 새로운 노드를 사용하여 처음부터 커스텀 물리 설정을 구축하는 방법과 시뮬레이션을 제어하는 다양한 방법을 다룹니다. 아티스트들은 노드 기반으로 더욱 유연하고 창의적인 시뮬레이션 효과를 만들 수 있게 됩니다.

애니메이션 레이어와 컴포지터의 진화

애니메이션 팀은 액션에 애니메이션 레이어를 도입하는 작업을 포함한 지난 1년간의 모듈 진행 상황과 향후 계획을 발표했습니다. 또한 Habib Gahbiche는 블렌더 스튜디오 아티스트들과의 협업 경험을 바탕으로 컴포지터의 로드맵과 새로운 기능들을 선보였습니다. 이를 통해 애니메이션 리깅과 후가공 작업의 효율성이 대폭 개선되고 있습니다.

렌더링 파이프라인과 내부 코드 현대화

Clément Foucault는 그래픽 API 간의 파편화와 코드 중복을 해결하기 위해 도입 중인 맞춤형 셰이딩 언어 BSL의 아키텍처 진화를 설명했습니다. 아울러 Bastien Montagne은 ID 관리 리팩토링 사례를 통해 코드 및 소프트웨어 아키텍처 품질 향상을 위한 리팩토링의 중요성을 강조했습니다. 저수준의 GPU 최적화와 모듈화는 장기적으로 소프트웨어의 안정성을 높여줍니다.

💡 에디터 코멘트

이번 BCON26 발표들은 단순히 미래의 기술 청사진을 제시하는 것을 넘어, 실무 파이프라인의 효율성을 극대화할 수 있는 실질적인 도구들을 대거 포함하고 있습니다. 특히 OpenPBR 도입과 지오메트리 노드를 통한 커스텀 물리 제어는 외부 DCC 툴과의 호환성을 높이고 시뮬레이션 작업의 자유도를 획기적으로 넓혀줄 것입니다. 안드로이드 포팅 빌드와 새로운 컴포지터 기능 역시 모바일 워크플로우와 실시간 합성 작업을 자주 다루는 3D 아티스트들에게 강력한 무기가 될 수 있습니다. 실무 도입을 앞두고 개발자 블로그와 테스트 빌드를 미리 점검하여 파이프라인 변화에 선제적으로 대비하는 것을 추천합니다.
