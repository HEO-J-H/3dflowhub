한 줄 요약 — NVIDIA Holoscan 5와 Pinocchio 라이브러리를 활용해 Seeed Studio reBot 팔의 중력 보상 제어 루프를 구축하는 방법입니다.

분류: AI 3D › 로보틱스·월드모델 › 튜토리얼·팁

Holoscan 5 기반 중력 보상 루프 구축

NVIDIA Holoscan 5는 단일 프로그래밍 모델 안에서 저지연 로봇 제어와 고처리량 인식을 동시에 처리합니다. 3개의 커스텀 오퍼레이터로 구성된 중력 보상 루프는 400 Hz 속도로 관절 상태를 읽습니다. 이 데이터는 Pinocchio를 통해 역동역학 계산을 거쳐 motorbridge 라이브러리로 Seeed Studio reBot Arm B601-DM에 토크 명령을 보냅니다.

파티션 구조와 큐를 통한 지연 시간 최적화

Holoscan 파티션은 오퍼레이터 체인을 단일 스레드에 그룹화하여 스레드 간 핸드오프와 불필요한 시스템 콜을 방지합니다. 클록 및 데이터 도착 트리거는 작업 실행 시점을 명시적으로 표현하며 드롭 올디스트 큐는 오래된 샘플이 쌓이는 것을 막아줍니다. 이를 통해 제어 경로의 지연 시간과 지터를 최소화합니다.

Nsight Systems 프로파일링 결과

내장된 NVTX 어노테이션이 포함된 Nsight Systems 프로파일링을 통해 성능을 측정할 수 있습니다. 제어 파티션을 특정 CPU 코어에 고정하는 설정은 C++ 구현의 p99.99 지연 시간을 약 5배 줄여줍니다. Python 구현의 경우 동일한 설정에서 지연 시간이 약 9.6배 감소하는 결과를 보여줍니다.
