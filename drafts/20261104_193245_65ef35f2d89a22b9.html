한 줄 요약 — Blender 초보자를 위한 Smart UV Project, Seam, Project from View 등 세 가지 UV 언랩 방식을 정리합니다.

분류: 3D DCC › Blender › 튜토리얼·팁

Smart UV Project를 활용한 자동 전개

Smart UV Project는 별도의 절개선 작업 없이 Blender가 자동으로 UV를 펼쳐주는 기능입니다. 원치 않는 위치에 절개선이 생기거나 조각이 많이 나뉠 수 있지만, 티가 잘 나지 않는 패턴 텍스처를 적용할 때 유용합니다. 설정 창에서 각도 조절 값을 변경하면 생성되는 조각 개수를 줄일 수 있습니다.

Mark Seam과 Unwrap 각도 기반 전개

원하는 부위에 직접 Mark Seam을 지정하고 나머지를 각도 기반으로 펼치는 방식입니다. 손이 많이 가지만 아티스트가 의도한 대로 정확하게 UV를 제어할 수 있어 정교한 텍스처 작업에 적합합니다.

Project from View를 활용한 투영 전개

현재 뷰포트에서 바라보는 시점 그대로 UV를 펼치는 방식입니다. 앞면과 뒷면의 모양이 동일해지고 측면은 납작하게 압축되므로, 세밀한 그림 표현보다는 그라데이션이나 단색 패턴을 입히는 작업에 알맞습니다.

❓ 자주 묻는 질문

Q. Blender에서 자동으로 UV를 가장 빨리 펴는 방법은 무엇인가요?
A. Smart UV Project를 사용하면 절개선 설정 없이 각도 설정만으로 빠르고 간편하게 UV를 펼칠 수 있습니다.

Q. 그라데이션 텍스처를 넣기 좋은 UV 전개 방식은 무엇인가요?
A. 현재 시점 그대로 형태를 투영하는 Project from View 방식이 그라데이션 활용에 적합합니다.
