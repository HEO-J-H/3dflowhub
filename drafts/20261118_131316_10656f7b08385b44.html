한 줄 요약 — Logitech MX Keypad는 9개의 커스텀 가능한 LCD 키와 15개 페이지를 제공하여 복잡한 Hotkey 조작을 돕는 유선 컨트롤 패드입니다.

분류: 3D DCC › 기타 DCC › 리뷰·비교

99.99달러 가격과 주요 하드웨어 제원

Logitech MX Keypad는 91.7 x 77.9 x 25.5mm 크기의 컴팩트한 유선 컨트롤 패드로 가격은 99.99달러 또는 89.99파운드입니다. 1.5m 길이의 USB-C to USB-C 케이블로 연결되며 Windows와 macOS 환경을 지원합니다. 3x3 Grid 형태로 배치된 9개의 물리 키는 각각 독립된 LCD 화면을 탑재해 할당된 기능을 아이콘으로 표시합니다.

Logi Options+ 앱 기반의 컨텍스트 인식

Logi Options+ 전용 Software를 통해 어도비 크리에이티브 클라우드, Figma, Blender, Clip Studio Paint 등 주요 크리에이티브 프로그램과 연동됩니다. 프로그램을 실행하면 자동으로 해당 Software의 프리셋이 불러와지며 사용자가 직접 액션을 수정하거나 생성할 수 있습니다. 최대 15개 페이지를 지원하여 총 135개의 커스텀 액션을 등록해 활용 가능합니다.

실제 사용 시 장단점과 지원 앱 범위

각 키에 아이콘이 시각적으로 표시되어 기존 매크로 패드와 달리 복잡한 Hotkey 조합을 외우지 않아도 되는 장점이 있습니다. 다만 유선 연결 방식만 지원하며 Rebelle이나 ArtRage 같은 일부 지원되지 않는 프로그램은 수동 설정이 필요합니다. 거치대 부분이 강하게 누를 때 밀릴 수 있다는 점도 실제 작업 환경에서 고려해야 할 부분입니다.
