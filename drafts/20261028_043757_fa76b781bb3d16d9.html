한 줄 요약 — 새로운 MPM 솔버가 강변형에서도 수치 파손 없이 완전 탄성 고체를 시뮬레이션하고 격자 기반 충돌을 자연스럽게 처리한다.

분류: VFX › 기타 VFX › 연구·논문

배경 및 문제점

Material Point Method(MPM)는 고체와 유체를 동시에 시뮬레이션하는 데 널리 쓰인다. 그러나 완전 탄성 고체를 다룰 때, 변형이 크게 일어나면 수치 파손이 발생해 물체가 비현실적으로 분리된다. 이는 플라스틱 변형이 없는데도 파손이 일어나기 때문에 시각적 일관성이 떨어진다.

기존 접근법의 한계

기존 연구는 레퍼런스 격자에서 힘을 계산해 파손을 방지했지만, 이는 격자와 충돌 처리 시스템이 호환되지 않는 문제를 야기한다. 고정 레퍼런스 격자를 사용하면 현재 격자 기반 충돌 로직을 적용하기 어렵다. 따라서 실제 게임이나 VFX 파이프라인에 바로 적용하기엔 제약이 많았다.

제안 방법의 핵심

본 논문은 현재 격자에서 탄성 힘을 계산하면서도 입자 위치와 고정 레퍼런스 격자를 이용해 변형을 직접 추정한다. 속도 구배에 기반한 업데이트를 배제해 입자 수준 충돌 처리와 영-에너지 모드 억제 기능을 자연스럽게 포함한다. 이를 통해 격자 기반 충돌 처리와 완전 탄성 시뮬레이션을 동시에 구현한다.

주요 결과 및 적용 사례

제안된 MPM 솔버는 강변형 상황에서도 수치 파손 없이 안정적으로 동작한다. 복잡한 접촉 시나리오에서도 기존 MPM 대비 파손 없이 물체가 변형되고 회복한다. 실험 결과는 대규모 변형을 포함한 탄성 물체 시뮬레이션에 적용 가능함을 보여준다.

향후 연구 방향

현재 방법은 완전 탄성에 초점을 맞추었으므로, 플라스틱 변형이나 손상 모델과의 결합이 필요하다. 또한 GPU 최적화를 통해 실시간 응용 분야로 확장할 여지가 있다. 다양한 VFX 파이프라인과의 인터페이스 표준화도 향후 과제로 남는다.

💡 에디터 코멘트

실시간 VFX Pipeline 강변형 탄성 물체를 다루는 팀은 기존 MPM의 수치 파손 문제로 어려움을 겪었다. 이번 논문의 방법은 현재 격자에서 힘을 계산하면서도 입자 위치와 고정 레퍼런스 격자를 이용해 변형을 직접 구해 파손을 방지한다. 충돌 처리와 영-에너지 모드 억제 메커니즘이 내장돼 있어 기존 파이프라인에 최소 수정으로 적용 가능하다. 특히 대규모 접촉 시뮬레이션이나 고체 파괴 효과가 필요 없는 물리 기반 애니메이션에 유용하다. 연구 결과를 기반으로 자체 엔진에 통합하면 물리 정확도와 안정성을 동시에 확보할 수 있다.

❓ 자주 묻는 질문

Q. 왜 기존 MPM은 강변형에서 파손이 발생하나요?
A. 기존 MPM은 변형을 속도 구배 기반으로 업데이트하면서 수치 오차가 누적돼 격자와 입자 간 불일치가 생겨 파손 현상이 나타난다.
