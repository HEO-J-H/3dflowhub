Blender 환경의 AI 모션 릭 확장 기능

아티스트가 직접 전체 애니메이션 시퀀스를 제작하고 기존 도구로 폴리싱할 수 있는 AI 기반 모션 릭 확장 기능 도입에 대한 논의입니다. 텍스트 입력 방식 대신 수동 조작과 결합된 형태를 지향합니다.

실시간 모션 디버깅과 작업 흐름

800~1000ms 범위의 실시간 피드백을 제공하며 Graph Editor, NLA, Action slots 등의 기존 기능과 단일 작업 흐름으로 통합됩니다. 비파괴적인 방식으로 작동하여 수정과 업데이트가 즉시 이루어집니다.

시스템 메모리 요구 사항

제안된 AI 모델은 매우 가볍게 설계되어 700MB의 메모리만으로 구동될 수 있습니다. 별도의 복잡한 텍스트 Prompt 입력 과정 없이 모션 제어에 집중할 수 있는 환경을 제공합니다.

💡 에디터 코멘트

700MB 메모리 용량과 800~1000ms 수준의 실시간 피드백을 목표로 설계된 모델은 텍스트 입력 없이 애니메이션 시퀀스를 직접 제작할 수 있는 가능성을 보여줍니다.
