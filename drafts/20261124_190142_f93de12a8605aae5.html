한 줄 요약 — Unity가 에이전트를 통한 자산 다운로드 및 자연어 검색이 가능한 Asset Library 플러그인을 오픈 베타로 공개했습니다.

분류: Game Engine › Unity › 업데이트·출시

Unity CLI 기반 에셋 자동 다운로드 및 배포

사용자가 선택한 에이전트가 직접 필요한 에셋을 찾고 다운로드하여 씬에 배치하는 방식을 지원합니다. 개발자는 수동으로 에셋을 찾는 과정을 거치지 않고 명령을 통해 필요한 리소스를 프로젝트에 즉시 반영할 수 있습니다.

자연어 기반 Asset Library 플러그인

평문 언어로 원하는 에셋을 설명하여 검색할 수 있는 기능을 제공합니다. 보유 중인 무료 에셋과 구매한 에셋 팩 중에서 필요한 항목만 정확히 골라 프로젝트에 통합하는 작업을 매끄럽게 처리합니다.

현재 오픈 베타 서비스 진행 중

해당 기능들은 현재 오픈 베타 단계로 제공되고 있으며, 프로젝트 환경에서 실무 테스트를 진행할 수 있습니다. 공식 링크를 통해 세부적인 연동 방법과 가이드를 확인할 수 있습니다.

💡 에디터 코멘트

자연어 입력 한 줄로 보유한 에셋 팩에서 필요한 오브젝트를 찾아 씬에 바로 끌어다 놓을 수 있는 Asset Library 플러그인이 도입되었습니다. 레벨 디자인 단계에서 에셋을 찾는 시간을 단축하여 씬 구성 작업을 간소화합니다.

❓ 자주 묻는 질문

Q. Unity Asset Library 플러그인은 어디서 사용할 수 있나요?
A. 현재 오픈 베타로 제공되고 있으며, 공식 링크와 Unity Package 매니저를 통해 접근할 수 있습니다.

Q. Unity CLI는 어떤 역할을 하나요?
A. 사용자가 지정한 에이전트가 에셋을 검색, 다운로드하고 씬에 직접 배치하는 작업을 자동화합니다.
