한 줄 요약 — Foundry가 Mari 8.0을 출시하며 50개 이상의 신규 노드와 Tri‑Planar Tiled, Hex Tile 등 텍스처 작업을 확장하는 기능을 추가했습니다.

분류: 3D DCC › Mari › 업데이트·출시

새로운 Node Graph 기능

Mari 8.0은 Node Graph에 50개가 넘는 신규 노드를 추가했습니다. 수학 연산, A/B 비교, 컬러 리맵, 트랜스폼 등 다양한 용도의 노드가 포함됩니다. 특히 49개의 수학 노드는 기본 연산부터 고급 랜덤화까지 지원해 프로시저 텍스처 제작이 쉬워집니다. 새로운 Compare 노드로 A/B 와이프 비교가 가능해 머티리얼 반복 테스트가 간편해졌습니다.

Tri‑Planar Tiled 노드

Tri‑Planar Tiled 노드는 기존 Triplanar Projection과 달리 단일 2D 이미지 텍스처를 X, Y, Z 축에 걸쳐 투사합니다. UV가 없거나 왜곡된 모델에도 고주파 디테일을 유지하면서 적용할 수 있습니다. Smart blend 모드가 포함돼 디테일 손실 없이 부드러운 블렌딩을 제공합니다. 이 노드는 복잡한 모델링 Pipeline UV 작업을 크게 감소시킵니다.

💡 에디터 코멘트

텍스처 아티스트에게 노드 기반 워크플로가 크게 강화됩니다. 특히 Tri‑Planar Tiled 노드는 UV가 없거나 왜곡된 모델에도 균일한 디테일을 적용할 수 있어 복잡한 UV 작업을 줄여줍니다. Hex Tile 노드는 반복 텍스처의 눈에 띄는 패턴을 최소화해 VFX Pipeline 흔히 쓰이는 기법을 그대로 Mari에 도입했습니다. 마스크 생성 기능이 확대돼 색상 ID 마스크와 멀티 컬러 마스크로 레이어별 제어가 쉬워집니다. 실시간 검색·트랙볼 네비게이션 등 UI 개선도 포함돼, 학생부터 시니어까지 빠르게 적응할 수 있습니다.
