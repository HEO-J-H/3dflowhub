Unity 6.7의 2D 그래픽 도구와 Physics Core 2D

Unity 6.7은 기존의 친숙한 제작 워크플로를 유지하면서도 강력한 물리 시뮬레이션을 제공하는 Physics Core 2D 컴포넌트를 도입합니다. 또한 원활하게 업그레이드할 수 있는 2D 그래픽 도구 모음이 포함되어 있습니다. 종합적인 2D 프로파일링 도구도 함께 제공되어 심층적인 성능 분석이 가능해집니다.

Bunny Blitz 샘플 게임과 런타임 성능 검증

새로운 물리 퍼즐 게임 샘플인 Bunny Blitz가 Unity Asset Store에 공개되었습니다. 이 샘플은 원활한 워크플로 통합과 향상된 런타임 속도를 직접 시연하기 위해 제작되었습니다. 개발자는 이를 통해 실제 프로젝트에 적용된 기능들을 직접 확인할 수 있습니다.

Unity 7의 RenderSprite API 확장 계획

Unity 7에서는 Tilemap 및 SpriteShape 같은 객체 전반에서 2D 렌더링 성능을 한 차원 더 끌어올리기 위해 RenderSprite API를 확장할 예정입니다. 대규모 2D 오브젝트를 다루는 게임에서 렌더링 속도 개선에 기여합니다.

💡 에디터 코멘트

Unity 6.7은 업그레이드가 매끄러운 2D 그래픽 도구와 Physics Core 2D를 도입해 물리 시뮬레이션 제작 과정을 간소화합니다. Tilemap과 SpriteShape 환경에서 런타임 속도를 높이려는 작업자라면 Unity 7의 RenderSprite API 확장 계획을 미리 확인해 두는 것이 좋습니다.
